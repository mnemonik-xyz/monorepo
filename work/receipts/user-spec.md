# Receipts: подписанный журнал памяти агента

Статус: черновик для владельца, 2026-10-11. Ничего из описанного ещё не
реализовано (всё — «запланировано»). Технические детали — в `tech-spec.md`,
открытые вопросы и решения — в `decisions.md`.

## Зачем

Разбор от 2026-10-11 (см. `decisions.md`, «Fixed inputs»): mem0 выигрывает,
потому что решает ежедневную боль «агент забыл или запомнил не то» и имеет
бенчмарки качества памяти. Mnemonic не участвует в этой гонке: у нас нет
извлечения фактов, нет ранжирования, нет оценок качества. Наш единственный
уникальный актив — подписанный, проверяемый без оператора артефакт.

Вывод: не конкурировать с mem0 за память, а стать **слоем доказательств** над
любым движком памяти. Одна фраза: *mem0 помнит — Mnemonic доказывает, что именно
он помнил.*

## Что делаем

1. **Receipt (квитанция)** — маленькая подписанная запись об одном изменении
   памяти (`ADD`, `UPDATE`, `DELETE`, `RESET`). В ней только хэши, идентификаторы
   и ссылки на предыдущую запись. Текста памяти в ней нет никогда.
2. **Ledger (журнал)** — цепочка квитанций: общая по журналу и отдельная по
   каждому scope (`user_id` / `agent_id` / `run_id`). Экспорт по одному
   пользователю проверяется сам по себе.
3. **Checkpoint** — Merkle-корень диапазона квитанций, подписанный тем же
   ключом. Единственное, что покидает машину при якорении (около 200 байт).
4. **`Ledger.wrap(memory)`** — одна строка поверх mem0 `Memory` / `AsyncMemory`
   (позже `MemoryClient`). API mem0 не меняется, память остаётся приватной,
   изменяемой и удаляемой.
5. **`mnemonik verify`** — офлайн-проверка экспорта по публичному ключу, без
   оператора и без движка памяти. **`mnemonik audit`** — сверка с собственной
   таблицей `history` mem0: находит пропуски и правки задним числом.

## Чего не делаем в v1

Графовую память mem0, квитанции на чтение, ротацию ключей, хостинг-нотариус,
другие движки. Платёжные рельсы, квоты, режимы записи и OAuth-вход не участвуют
в пути записи.

## Критерий успеха

Через 90 дней: пять дизайн-партнёров запускают `verify` на своих экспортах без
нашей помощи, и хотя бы один готов платить за нотариус/хранение чекпойнтов.
Если нет — тезис «кому-то нужно доказательство памяти агента» опровергнут.
