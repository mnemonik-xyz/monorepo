# User Spec: Mnemonic, который можно показать и попробовать

## Суть

Новый человек за 5 минут и без кошелька должен увидеть три вещи:
агент **помнит**, агент может **поделиться** памятью, и любой может
**проверить**, кто её написал.

## Проблема

- Локальный MCP спрашивал разблокировку keychain в каждой сессии
  (исправлено в этой ветке: ключ нужен только для share/anchor).
- Запись on-chain требует кошелёк с USDC; SDK и webapp не показывают шаг
  оплаты. После включения оплаты новых пользователей не было
  (в цепочке: 16 записей от 3 пользователей, 2026-05-02…05-20).
- Поделиться одной памятью нельзя: нет ссылки, нет импорта, проверка
  требует аккаунта.

## Что хотим

1. Локальная память: бесплатно, без запросов keychain, общая для всех
   инструментов на машине.
2. Поделиться по ссылке: память подписана ключом автора; открывший ссылку
   видит автора и «подпись верна» без регистрации.
3. Импорт: агент получателя импортирует память и помнит, от кого она.
4. Anchor on-chain: первые N бесплатно, дальше цена видна заранее.

## Не делаем сейчас

Командные пространства (spaces), A2A-мост, смена ширины TurboQuant.

## Критерии готовности

- Демо-сценарий из `plan.md` проходит на чистой машине < 5 минут.
- Ни один шаг демо не требует кошелька или OAuth, кроме необязательного
  anchor после квоты.
- Подделанная ссылка показывает «подпись неверна».
