# Task 1: Workspace scaffold + turboquant migration

## Required Skills

Before starting, load: `/skill:code-writing` — [SKILL.md](/home/claude/.claude/skills/code-writing/SKILL.md)

## Description

Create the Cargo workspace root and the `mnemonic-core` library crate skeleton, then migrate the `turboquant` git dependency to `turboquant-plus-rs` from crates.io. This is the mandatory first task — nothing else can proceed until the workspace structure compiles and the crates.io-published compression crate is wired in.

Currently, `mnemonic-protocol/mcp/` is a standalone binary crate with all domain logic embedded directly. The goal of this task is:
1. Introduce a workspace root `Cargo.toml` at `mnemonic-refactored/` so that `core/` and `mcp/` are workspace members.
2. Create `core/Cargo.toml` as a library crate with all domain dependencies declared (even though modules are empty stubs at this point).
3. Create `core/src/lib.rs` with eight `pub mod` stubs — one per domain module that will be extracted in subsequent tasks.
4. Update `mcp/Cargo.toml` to: replace the `turboquant` git dependency with `turboquant-plus-rs = "0.1.0"`, add `mnemonic-core = { path = "../core" }`, and remove `solana-client` (which lives in core after full extraction).
5. Update all `turboquant::` import paths in `mcp/src/compress.rs` to `turboquant_plus_rs::`.

After this task, `cargo build -p mnemonic-core` and `cargo build -p mnemonic-mcp` must both succeed. The MCP server is not yet using core types — that happens in waves 2–11.

   - `[workspace]` with `members = ["core", "mcp"]` and `resolver = "2"`.
   - No `[package]` section — this is a workspace-only manifest.

3. **Create `core/Cargo.toml`** with:
   - `[package]` name = `"mnemonic-core"`, edition = `"2021"`, version = `"0.1.0"`.
   - `[lib]` target (default lib target, no explicit path needed unless `src/lib.rs` exists).
   - All domain dependencies from the list in the Details section below.
   - `[features]` with `local-embed = ["fastembed"]`.
   - `[dev-dependencies]`: `httpmock = "0.8"`, `tempfile = "3"`, `proptest = "1"`, `criterion = "0.5"`, `tokio` with features `["macros", "rt-multi-thread"]`.

4. **Create `core/src/lib.rs`** with eight `pub mod` stubs — one line each, commented with the module's purpose:
   - `codec`, `identity`, `embed`, `compress`, `storage`, `arweave`, `solana`, `lineage`
   - Each stub must have a corresponding empty `core/src/<module>/mod.rs` (or `core/src/<module>.rs`) so it compiles. Use module directories (`core/src/codec/mod.rs`, etc.) to match the target layout used in later tasks.

5. **Update `mcp/Cargo.toml`** (source at `/home/claude/.openclaw/workspace/mnemonic-protocol/mcp/Cargo.toml`, target workspace location `mnemonic-refactored/mcp/Cargo.toml`):
   - Replace `turboquant = { git = "https://github.com/sivo4kin/turboquant-rs.git", branch = "master" }` with `turboquant-plus-rs = "0.1.0"`.
   - Add `mnemonic-core = { path = "../core" }`.
   - Remove `solana-client = "2.2"` and `solana-transaction-status = "2.2"` entries (they will live in core after full extraction, but removing them now avoids having unused deps; confirm they are only used in solana.rs before removing).

6. **Update `mcp/src/compress.rs`** (source at `/home/claude/.openclaw/workspace/mnemonic-protocol/mcp/src/compress.rs`): change all `turboquant::` references to `turboquant_plus_rs::`. The import line `use turboquant::{pack_bits, pack_indices, TurboQuant};` becomes `use turboquant_plus_rs::{pack_bits, pack_indices, TurboQuant};`. Scan the rest of the file for any other `turboquant::` occurrences and update them all.

7. **Verify:** Run `cargo build -p mnemonic-core && cargo build -p mnemonic-mcp` from the workspace root. Both must succeed with zero errors.
