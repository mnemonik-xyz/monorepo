# Task 13: Code Audit

## Required Skills

Before starting, load: `/skill:code-reviewing` — [SKILL.md](/home/claude/.claude/skills/code-reviewing/SKILL.md)

## Description

Full-feature code quality audit of the mnemonic-core extraction. After all implementation waves (1–12) are complete, this task reviews the entire extracted codebase for cross-component correctness — things that individual task reviewers may miss because they only saw one module at a time.

The auditor reads all source files in `core/src/` and the post-extraction `mcp/src/`, then checks for three categories of issues:

1. **Import consistency** — every domain type used in `mcp/` must be imported from `mnemonic_core::`. No lingering `use crate::` or relative paths to domain modules that were extracted. Stale `mod` declarations in `mcp/src/main.rs` for modules that now live in core must be absent.

2. **Public API surface correctness** — `core/src/lib.rs` must re-export exactly the eight modules: `codec`, `embed`, `compress`, `identity`, `storage`, `arweave`, `solana`, `lineage`. Nothing more, nothing less. All types that `mcp/` uses from core must be reachable through these re-exports (no `pub(crate)` items consumed cross-crate). No private implementation detail leaked into the public API.

3. **Architectural consistency** — domain logic must not have migrated back into `mcp/`. Specifically: `pricing.rs` must be unchanged (not moved, not modified); all eight payment methods (`create_api_key`, `deduct_balance`, `credit_deposit`, `mark_x402_nonce`, `record_attestation_cost`, `get_pnl_stats`, `get_owner_pubkey`, `verify_usdc_transfer`) must be absent from `core/src/`; `HashEmbedder` must be absent from `core/src/`; no domain structs (e.g., `AttestationRow`, `CompressedEmbedding`) duplicated between core and mcp.

The task executor IS the reviewer — there are no downstream reviewers for this audit task. The output is findings (reported in post-completion decisions.md), not a changed codebase. If critical issues are found, they should be filed as follow-up tasks or fixed inline if trivial.

## What to do

1. **Read all core source files** — every `.rs` file under `core/src/`. For each module, note: what it exports, whether imports are clean (no leftover `crate::` or mcp paths), whether public items are appropriate (not over-exposed, not under-exposed).

2. **Read all mcp source files** — `mcp/src/main.rs`, `mcp/src/mcp.rs`, `mcp/src/tools.rs`, `mcp/src/payment.rs`, `mcp/src/pricing.rs`, `mcp/src/config.rs`. For each file, verify all domain type imports come from `mnemonic_core::` and no domain logic was added or retained.

3. **Check Cargo manifests** — `Cargo.toml` (workspace root), `core/Cargo.toml`, `mcp/Cargo.toml`. Verify workspace structure (`members = ["core", "mcp"]`, `resolver = "2"`), that `core/Cargo.toml` does not contain axum/tokio-full/clap (server-only deps), and that `mcp/Cargo.toml` depends on `mnemonic-core = { path = "../core" }` and does not re-declare domain crates (sha2, blake3, etc.) unless genuinely needed for mcp-specific code.

4. **Run boundary grep checks** — execute the four canonical greps from the Agent Verification Plan:
   - `grep -r "HashEmbedder" core/src/` — must be empty
   - `grep -r "create_api_key\|deduct_balance\|credit_deposit\|mark_x402_nonce\|record_attestation_cost\|get_pnl_stats\|get_owner_pubkey\|verify_usdc_transfer" core/src/` — must be empty
   - `grep -E "codec/|lineage/" .claude/skills/project-knowledge/references/architecture.md` — must return both lines (Task 12 output)
   - `grep -r "pricing" core/src/` — must be empty (pricing.rs must remain solely in mcp/)

5. **Verify `core/src/lib.rs`** — confirm exactly eight `pub mod` declarations and that all eight are present.

6. **Check `mcp/src/main.rs` and `mcp/src/tools.rs`** — verify no `mod codec;`, `mod identity;`, `mod embed;`, etc. remain (modules that moved to core). Verify `use mnemonic_core::` is the pattern used for domain types.

7. **Compile check** — run `cargo build --workspace` and `cargo test --workspace` and `cargo clippy --workspace -- -D warnings` to confirm the full workspace is green after all waves.

8. **Produce findings** — categorize issues as: CRITICAL (architectural boundary violation, payment method in core, builds broken), MAJOR (import inconsistency, missing re-export, domain logic duplication), MINOR (unused imports, dead code, clippy lint not caught by -D warnings), INFO (style, naming suggestions). Report all findings with file paths and line numbers.

## Details

**Audit scope — what to look for in each component:**

`core/src/lib.rs` — check for exactly 8 `pub mod` declarations. No `pub use` re-exporting internal items at the crate root unless explicitly needed for the public API. No `mod` without `pub`.

`core/src/codec/` — imports should only use `std::`, `serde`, `sha2`, `hex`, `base64`, `blake3`, `ciborium`, `coset`, `uuid`. No `mcp` references. All public types used in `mcp/tools.rs` must be `pub` here.

`core/src/identity/` — imports: `solana-sdk`, `bs58`, `anyhow`. No payment references. `load_or_create_keypair` must be `pub`.

`core/src/embed/` — imports: `reqwest`, `ndarray`, `anyhow`, optionally `fastembed`. `MockEmbedder` must be `#[cfg(test)]` only. `HashEmbedder` must be absent entirely (no commented-out code either). `Embedder` trait must be `pub`.

`core/src/compress/` — imports: `turboquant_plus_rs`, `ndarray`, `anyhow`. No `turboquant::` namespace references remaining.

`core/src/storage/` — traits `AttestationStore` and `LineageStore` must be `pub`. SQLite impl in `sqlite.rs`. Payment methods (`create_api_key`, etc.) must be absent. Trait-level rustdoc must document that authorization is the caller's responsibility (per Decision 8).

`core/src/arweave/` — imports: `reqwest`, `serde_json`, `anyhow`, `tokio`. No mainnet URLs hardcoded outside of test helpers. `ArweaveClient` must be `pub`.

`core/src/solana/` — imports: `reqwest`, `solana-sdk`, `spl-memo`, `anyhow`, `tokio`. `verify_usdc_transfer` must NOT be present — it lives in `mcp/src/payment.rs`. `SolanaClient` must be `pub`.

`core/src/lineage/` — `Direction` must be an enum (not `String`). `chain_valid` field must be `Option<bool>` (not `bool` or `String`). DB error paths must use `?` operator (search for `.unwrap()` on `Result` values inside non-test code).

`mcp/src/tools.rs` — all domain imports from `mnemonic_core::`. No `use crate::codec`, `use crate::embed`, etc. No domain structs defined locally that duplicate core types.

`mcp/src/payment.rs` — must contain `verify_usdc_transfer` as a standalone async function (not a method on `SolanaClient`). Must contain all 7 other payment methods. Nothing from this file should appear in core/.

`mcp/src/pricing.rs` — must be unchanged from pre-migration state. No references to `mnemonic_core::` (pricing is pure mcp logic).

`mcp/src/main.rs` — must not contain `mod codec;`, `mod embed;`, `mod compress;`, `mod identity;`, `mod storage;`, `mod arweave;`, `mod solana;`, `mod lineage;` (all were moved to core). May contain `mod tools;`, `mod mcp;`, `mod payment;`, `mod pricing;`, `mod config;`.

**Workspace Cargo.toml checks:**

`Cargo.toml` (workspace root): `members = ["core", "mcp"]`, `resolver = "2"`. No `[package]` section.

`core/Cargo.toml`: no axum, no tower-http, no clap, no tokio-full (only `time` and `rt` features needed). Has `turboquant-plus-rs = "0.1.0"`, not `turboquant = { git = "..." }`. Has `rusqlite = { version = "0.34", features = ["bundled"] }`. Has `[features]` with `local-embed = ["fastembed"]`.

`mcp/Cargo.toml`: has `mnemonic-core = { path = "../core" }`. Has axum, tokio (full), clap. Does not re-declare domain deps already in core (sha2, blake3, ndarray, turboquant-plus-rs, etc.) unless mcp genuinely uses them directly.

**Edge cases to check:**

- Duplicate type definitions: search for `struct AttestationRow`, `struct CompressedEmbedding`, `struct SignedArtifact`, `enum Direction` in mcp/src/ — must not appear (moved to core).
- Test-only code in non-test modules: `MockEmbedder` must be behind `#[cfg(test)]`. No test utilities in production paths of core.
- Circular dependency risk: `mcp/` depends on `core/`, but `core/` must have zero references to any `mcp` crate. Check `core/Cargo.toml` for any `mnemonic-mcp` or `mcp` dependency entries.
- `verify_usdc_transfer` isolation: grep `core/src/` for `verify_usdc_transfer` — must be empty. Grep `mcp/src/payment.rs` for `verify_usdc_transfer` — must be present.
