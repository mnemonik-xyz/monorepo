# Task 2: Extract codec module

## Required Skills

Before starting, load: `/skill:code-writing` — [SKILL.md](/home/claude/.claude/skills/code-writing/SKILL.md)

## Description

Move the codec module (schema, canonical, hash, sign) from `mcp/src/codec/` to the new `core/src/codec/` crate. Update all import paths in `mcp/` to reference `mnemonic_core::codec` instead of the local `codec::` module. After this task, `mcp/` must have no own codec module — all codec types and functions come exclusively from `mnemonic_core::`.

Codec is the cleanest extraction target: it has zero internal dependencies on other `mcp/` modules (no db, embed, compress, identity imports). It depends only on external crates (`ciborium`, `coset`, `blake3`, `sha2`, `serde`, `chrono`, `base64`, `solana-sdk`). All 24 existing codec tests travel with the module and must pass after the move.

This task delivers the first piece of real domain logic living in `core/`, validating the workspace scaffold from Task 1.

## What to do

1. Create `core/src/codec/` directory with five files: `mod.rs`, `schema.rs`, `canonical.rs`, `hash.rs`, `sign.rs` — copy source from `mcp/src/codec/` verbatim.

2. Update all `use crate::codec::` references inside the copied codec files to `use super::` or intra-module paths (since they move from `crate::codec::X` to `mnemonic_core::codec::X`, internal references like `use super::canonical::to_canonical_cbor` are already correct — confirm they resolve within the module).

3. Add `pub mod codec;` to `core/src/lib.rs`.

4. Verify `core/Cargo.toml` has all codec dependencies: `ciborium`, `coset`, `blake3`, `chrono`, `base64`, `serde`, `serde_json`, `solana-sdk`. Add any that are missing.

5. Delete `mcp/src/codec/` directory (all five files).

6. Update `mcp/src/tools.rs`: replace `crate::codec::` import paths with `mnemonic_core::codec::` paths.

7. Update `mcp/src/mcp.rs`: same import update — any `crate::codec::` references become `mnemonic_core::codec::`.

8. Run `cargo test -p mnemonic-core -- codec` — all 24 tests must pass.

9. Run `cargo clippy -p mnemonic-core -- -D warnings` — zero warnings.

10. Run `cargo build -p mnemonic-mcp` — must compile without errors.
