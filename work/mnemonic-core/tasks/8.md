## Description

Move `solana.rs` from `mcp/src/` to `core/src/solana/mod.rs`, but with one critical extraction: `verify_usdc_transfer` must NOT come along. **Writing httpmock tests:**

Each test creates a `MockServer::start()` from httpmock, then constructs `SolanaClient::new(&server.base_url())`. The mock server intercepts JSON-RPC POST requests and returns crafted JSON responses. Use `server.mock(|when, then| { ... })` to set up expectations.

For `write_memo`, the test needs to mock three sequential RPC calls: `getLatestBlockhash` (returns a valid base58 hash), `sendTransaction` (returns a fake signature), and `getSignatureStatuses` (returns confirmed status). Use a test keypair generated with `Keypair::new()` — no funded keypair needed since the test server accepts anything.

For the retry exhaustion test, mock `getSignatureStatuses` to always return `{"value": [null]}` — the confirm loop should exhaust 30 retries and return `Err("not confirmed")`. To avoid a ~15-second wall-clock test, use Tokio's mock clock: annotate the test with `#[tokio::test(flavor = "current_thread", start_paused = true)]` and call `tokio::time::pause()` at the start of the test body. With the clock paused, each `tokio::time::sleep(Duration::from_millis(500))` inside `confirm_tx` advances Tokio's virtual time instantly — all 30 retries complete in microseconds of real time.

For `test_rpc_error_handling`, return a body like `{"jsonrpc":"2.0","id":1,"error":{"code":-32601,"message":"method not found"}}` — the `rpc()` helper checks for a non-null `error` field and bails.

**Accessing private `rpc` method from tests:**

The `rpc` method is currently `async fn rpc(...)` (private). Tests use public methods like `health_check`, `read_memo`, etc., which call `rpc` internally. No need to make `rpc` public. The `confirm_tx` retry exhaustion is best tested through `airdrop` or `write_memo` — these call `confirm_tx` internally.

**Edge cases:**

- `read_memo` log parsing: only extracts memo when the log string contains both "Memo" and "len". The substring extraction uses `find('"')` / `rfind('"')` — test with a realistic log format like `"Program log: Memo (len 42): \"<json here>\""`.
- `get_tx_signers` on a null transaction: returns `Ok(vec![])` — no error.
- Health check failure: if the mock server returns an error body, `health_check` returns `false` (swallows the error).

**Security:**

Tests must not contain any real Solana RPC URLs (`https://api.mainnet-beta.solana.com`, `https://api.devnet.solana.com`), no private key bytes, no funded keypair seeds. Always use `Keypair::new()` (random ephemeral keypair) or a fixed test seed that is obviously fake. The Gitleaks pre-commit hook will block commits containing real private key patterns.
