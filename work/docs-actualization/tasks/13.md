## What to do

1. **Secret scan term set:**
   - API keys: `sk-`, `xoxb-`, `ghp_`, `ghs_`, `gho_`, `hf_`, `pplx-`, `Bearer `, `AKIA`, `AIza`, `eyJ` (likely JWT)
   - Mnemonic phrases: words appearing in BIP39 lists (high false-positive rate; check context only)
   - Private keys: `-----BEGIN`, `-----END`, `PRIVATE KEY`
   - Mainnet keypairs: hex-encoded 64-char strings near `solana`/`keypair`/`secret`
   - Internal hostnames: `mnemonik.xyz` is public; flag any internal `*.local`, `localhost`, IP ranges (10/8, 192.168/16, 172.16/12)
   - Token shapes: `[A-Za-z0-9]{32,}` near words `token|key|secret|password|api`

2. **Run grep across the corpus:**
   ```bash
   grep -RInE 'sk-[A-Za-z0-9]{20,}|xoxb-[A-Za-z0-9-]{20,}|ghp_[A-Za-z0-9]{20,}|hf_[A-Za-z0-9]{20,}|pplx-[A-Za-z0-9]{20,}|AKIA[0-9A-Z]{16}|AIza[A-Za-z0-9_-]{20,}|-----BEGIN' \
     docs/ README.md .claude/skills/project-knowledge/references/ .claude/skills/project-knowledge/recovered/
   ```
   Note: zero hits expected. Any hit is a potential leak.

3. **PDF text extraction.** Run `pdftotext docs/research/paper.pdf - | head -200` and `pdftotext 'docs/research/Agent Identity for Autonomous AI_ Protocols, Mnemonic Analysis, and the Path to a Minimal Primitive.pdf' -`. Apply the same secret-scan term set against extracted text. Pay attention to author email addresses, internal repo URLs, embedded fonts/metadata that may contain auth tokens.

4. **Table inspection.** Open `docs/competitive-landscape/DRAG_ANALYSIS.md` and `docs/competitive-landscape/WEB_RESEARCH_TRUSTLESS_RAG.md`; visually scan tables for strings that look like keys, hashes, or addresses. The owner-pubkey of the production deploy (`DYVu4Bry3BzGVsR3Hj2iGVT5fNdWFoHw2zRxsdTmrG25` per `deployment.md`) is public; do not flag.

5. **License & attribution.** Confirm the foundational `paper.pdf` has either a clear license note in its body or an accompanying attribution in `docs/research/README.md` (the latter was authored in Task 5). If neither exists, flag for owner decision.
