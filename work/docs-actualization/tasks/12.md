## Description

Holistic read-only audit of the docs/ tree and PK refs after Wave 4. Verify cross-document link integrity (every relative link resolves), README presence per subfolder, file naming consistency, WHITEPAPER §9 cross-references match `docs/usecases/` filenames, PK refs land at correct anchors, and `recovered/README.md` extension reflects the actual restored content. Produce a JSON report under `logs/working/task-12/`. No file modifications.

## What to do

1. **Link integrity scan.** Run `lychee --offline` against all changed docs (or use `grep` to enumerate every relative link in changed files and `test -e` each target). Capture broken links per file.

2. **README presence per subfolder.** Verify each new `docs/<subdir>/` (`usecases/`, `competitive-landscape/`, `research/`, `problems/`) has a `README.md`. Confirm each README briefly explains the subdir purpose and lists the contents.

3. **File-naming consistency.** Within each subdir, confirm naming is consistent (kebab-case vs SCREAMING_CASE per upstream original). Note any divergence that should be normalized later (do not fix now — out of scope).

4. **WHITEPAPER §9 cross-refs.** For each `### 9.X` subsection, confirm the `docs/usecases/<file>.md` it points to exists. Confirm there are no §9 entries that point to non-existent files.

5. **PK refs land correctly.** For `project.md` Use Case Roles bullets and `architecture.md` Further reading section, confirm each link target file exists at the exact relative path.

6. **recovered/README.md sanity.** Confirm the README extension (added in Task 1) matches the actual `recovered/` tree state: every restored file appears in the table; every drop note matches an actually-not-restored file; promotion note placeholder is present (the actual hash is filled at PR-merge time).

7. **WHITEPAPER §10 / §13 cross-check.** Re-read these sections looking for residual claims contradicted by §9 expansion or by `docs/competitive-landscape/`, `docs/problems/`. Note (do not fix) any contradiction.

8. **Output JSON report** to `work/docs-actualization/logs/working/task-12/code-reviewer-1.json` with fields:
   ```json

     "task_id": 12,
     "verdict": "approved" | "needs-fix",

     "missing_readmes": ["..."],
     "naming_inconsistencies": ["..."],
     "whitepaper_cross_ref_issues": ["..."],
     "pk_ref_issues": ["..."],
     "recovered_readme_issues": ["..."],
   ```
