# Task 1: Durable paid-operation core

Add the provider-neutral payment contract and a restart-safe paid-operation
store. Bind each operation to the authenticated signer, correlation ID,
client-signed artifact hash, amount, asset, network, recipient, and expiry.

## Acceptance criteria

- [x] Local writes never create paid operations.
- [x] One operation ID has one immutable binding and at most one receipt.
- [x] State and signed payload survive MCP restart.
- [x] Recall of anchored artifacts never reads payment state.
- [x] Unit tests cover binding mismatch, idempotent replay, and state recovery.
