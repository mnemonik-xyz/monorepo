# Task 4: Universal Paywall synchronous session API

Implement the versioned session, settle, receipt, and status contract required
by the Mnemonic provider client. Enforce the fixed payee and all wallet-approved
session bounds. Use durable idempotency and reconcile uncertain chain results.

## Acceptance criteria

- [ ] Session registration validates the typed wallet authorization.
- [ ] Settlement enforces cap, ceiling, expiry, payee, scope, and funded balance.
- [ ] Concurrent settle calls return one durable signed receipt.
- [ ] One-time exact x402 uses the same operation binding and receipt schema.
- [ ] No reserve/commit/release or batching is introduced in V1.
