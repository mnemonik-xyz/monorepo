# Task 2: Settle after client signature and before anchoring

Move the paid HTTP gate from the initial `mnemonic_sign_memory` request to the
verified sign callback. Support a capped-session authorization as the primary
method and one-time x402 as the optional method. Persist `payment_ready` before
starting Irys or Solana work.

## Acceptance criteria

- [x] An unsigned artifact cannot be charged.
- [x] A paid callback without authorization returns a typed 402 quote.
- [x] Session settlement is synchronous and idempotent by operation ID.
- [x] One-time x402 is bound to the same operation and remains optional.
- [x] Chain clients are not called unless a durable settled receipt exists.
- [x] Delivery retry reuses the receipt and never settles again.
