# Task 4: OAuth 2.1 + PKCE server module

## Required Skills

Before starting, load: `/skill:code-writing` — [SKILL.md](/Users/syi/.claude/skills/code-writing/SKILL.md)

## Description

Implement `mcp/src/oauth.rs` per Decisions 9, 10, 11 in tech-spec. The module provides the two OAuth 2.1 endpoints (`/oauth/authorize`, `/oauth/token`), HS256 JWT issuance, a Bearer-auth Axum middleware with an explicit allowlist, per-IP rate limiting via `tower_governor`, and a tightened CORS policy. It also wires the mandatory ownership filter end-to-end: `core/src/storage/sqlite.rs::search` and the matching trait grow a non-optional `owner_pubkey: &str` parameter, and an idempotent column-add migration runs on first DB connection.

This task closes the security boundary required for the public Smithery-listed deployment: anonymous `/mcp tools/call` returns 401, recall results are scoped to `jwt.sub`, and PKCE downgrades / `alg=none` JWT submissions are rejected at the protocol layer. After this task, Cursor and Claude.ai connector installs can complete the OAuth handshake against `mcp.mnemonik.xyz` and obtain a valid JWT bound to the user's Mnemonic pubkey.

**Dependencies:**

- Depends on Task 1 (workspace + crate setup with `mnemonic-core` library available). Without Task 1's scaffolding, the storage trait edits cannot compile.
- Wave-2 sibling Task 4b reuses `bearer_auth_middleware` and the `Claims` extension on the request — keep the public API stable so 4b's `pending.rs` can read `jwt.sub` the same way.

**Edge cases:**

- `MCP_JWT_SECRET` must abort startup with a clear error if absent or shorter than 32 bytes (no fallback default — silent fallbacks are how secret leaks happen).
- The bearer middleware needs to peek into the JSON-RPC body to allowlist `initialize` and `tools/list`. Buffer the body via `axum::body::to_bytes` with a small cap (e.g., 1 MiB), parse just the `method` field, then reconstruct the request — do not consume the body irrevocably.
- `tower_governor = "=0.8.0"` is pinned because it is the version compatible with `governor = "0.8"` (already used by `pricing.rs`). `tower_governor 0.5.x` requires `governor 0.6` and will trigger a duplicate-major resolution failure. If a future bump is needed, run `cargo tree -p governor` after the change and confirm a single major remains; document any change in `decisions.md`.
- Migration is idempotent across deploys: `PRAGMA table_info` is the single source of truth, never `IF NOT EXISTS` (SQLite `ALTER TABLE` does not support it for `ADD COLUMN`).
- Stdio transport must continue to work without OAuth: the local-keypair pubkey resolves both `save` and `search` `owner_pubkey` parameters.
- CORS preflight: `tower_http::cors::CorsLayer` must explicitly allow `OPTIONS` so browsers do not get 405 on preflight.

**Implementation hints:**

- Keep `OAuthState` `Send + Sync + 'static` — wrap the `LruCache` in a `parking_lot::Mutex` (or `tokio::sync::Mutex` if any handler holds it across `.await`; with `LruCache` operations being cheap, prefer `parking_lot` and never await while holding).
- Reuse `mnemonic_core::codec::canonical::to_canonical_cbor` for the challenge encoding — do not roll your own. The same primitive is used across the codebase for COSE.
- `jsonwebtoken::Validation::new(Algorithm::HS256)` plus `validation.set_audience(&["mcp"])` and `validation.iss = Some([("mcp.mnemonik.xyz".to_string())].into_iter().collect())`. This is the pattern that closes the `alg=none` and `iss/aud` confusion attacks.
- For the body-peek allowlist, consider extracting a small `extract_json_rpc_method(bytes: &[u8]) -> Option<&str>` helper so it is unit-testable.
- The `tower_governor` layer is the outermost layer (so 429 returns before auth checks waste CPU on JWT verify); confirm with `rate_limit_routing.rs` that ordering is correct.
- For step 13's smoke script, use `cargo run -p mnemonic-mcp --release -- --transport http --port 0` with `STORAGE_MODE=local` and `EMBED_PROVIDER=mock` (or `fastembed` if the local model is cached); set `MCP_JWT_SECRET=$(openssl rand -base64 32)`; bind to an ephemeral port and read it from the server's startup line.
- Architectural rule from CLAUDE.md: nothing in `core/` may reference `axum`, `oauth2`, `jsonwebtoken`, or `tower_governor`. The migration helper in `core/src/storage/sqlite.rs` only adds columns — no auth logic crosses the boundary.
