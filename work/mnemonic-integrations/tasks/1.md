# Task 1: Streamable HTTP transport upgrade

## Required Skills

Before starting, load: `/skill:code-writing` — [SKILL.md](/Users/syi/.claude/skills/code-writing/SKILL.md)

## Description

Upgrade the HTTP transport in `mcp/src/main.rs` and `mcp/src/mcp.rs` from the current request-response JSON-RPC POST to **MCP streamable HTTP** per the 2025 specification. The current implementation (`mcp/src/main.rs:559-591` `run_http`, `mcp/src/main.rs:65-100` `mcp_handler`) returns a single buffered `Json<JsonRpcResponse>` per request — Anthropic and OpenAI custom-connector tiers reject this and require chunked `Transfer-Encoding: chunked` with NDJSON-framed events (one JSON-RPC frame per line). Without this upgrade Smithery / Cursor / Claude.ai Pro cannot accept `mcp.mnemonik.xyz` as a connector (Decision 1, R1).

This task also lays the **scaffolding** for OAuth Bearer middleware that Task 4a will fill in: introduce a no-op `tower::Layer` (or Axum `from_fn` middleware) attached to the `/mcp` route. It must accept any header today (no auth enforcement) but expose a clear extension point so Task 4a can swap in JWT validation without touching transport code. Stdio transport (`mcp/src/main.rs:517-555` `run_stdio`) is **unchanged** — line-delimited JSON over stdin/stdout continues to work for Cursor/Claude Desktop self-host.

After this task: `POST /mcp` returns `Content-Type: application/x-ndjson` with `Transfer-Encoding: chunked`, a single response is one frame, and the client-disconnect path does not panic mid-stream. The middleware layer is registered but pass-through.

## What to do

1. **Read current state.** Open `mcp/src/main.rs` (focus: `run_http` lines 559-591, `mcp_handler` lines 65-100) and `mcp/src/mcp.rs` (focus: `handle_request` lines 162-199, `McpState` lines 48-99). Confirm: `mcp_handler` returns a buffered `Response` via `Json(...)`; the `/mcp` route is plain `post(mcp_handler)`; CORS is currently `Any` (Task 4a will narrow this — leave for now).

2. **Convert `mcp_handler` to streaming.** Change its return type from `Response` to a streaming response (e.g. `axum::response::Response<axum::body::Body>` with a `Body::from_stream`). Use `futures::stream` (added explicitly to `mcp/Cargo.toml` in step 5) or `tokio_stream::wrappers::ReceiverStream` to feed NDJSON frames. Each frame = one JSON-RPC response object serialized via `serde_json::to_string` + `\n` terminator. Set headers: `Content-Type: application/x-ndjson`, `Transfer-Encoding: chunked` (axum auto-sets when `Content-Length` is absent). For the current single-response shape, emit exactly one frame per inbound request — multi-frame support (e.g. progress notifications) is wired but unused.

3. **Preserve payment gating semantics.** The existing payment branch (`is_sign_memory && state.payment_mode != "none" && state.storage_mode != "local"`, lines 70-100) must still execute before tool dispatch. On `payment::PaymentGate::NeedPayment(x402)`, emit the 402 body (the `x402` payload) as a single NDJSON frame with the appropriate HTTP status. On `deduct_balance` failure, same — one frame, status 402.

4. **Add no-op middleware scaffolding.** Create a `tower` middleware (recommend `axum::middleware::from_fn` or a small struct implementing `tower::Service`) named `bearer_auth_layer` (or similar). Today it inspects `Authorization` header but always calls `next.run(req).await` regardless. Add a `TODO(task-4a)` comment marking where JWT validation will plug in. Attach via `.layer(middleware::from_fn(bearer_auth_layer))` on the `/mcp` route only (not `/chat`, `/health`, `/oauth/*`).

5. **Update `mcp/Cargo.toml`.** Add the streaming deps explicitly: `futures = "0.3"` (required directly — do not rely on it being a transitive of axum) and `tokio-stream = "0.1"` if not already present. **Do not** add `oauth2`, `jsonwebtoken`, or `tower_governor` — those belong to Task 4a. Keep diff minimal otherwise.

6. **Stdio path unchanged.** Verify `run_stdio` at `mcp/src/main.rs:517-555` is untouched. Add a regression test ensuring stdio still produces line-delimited single-JSON responses.

7. **Add unit tests in `mcp/src/mcp.rs`** under `#[cfg(test)] mod tests`:
   - `test_chunked_response_encoding` — POST a `tools/list` request to a test `Router`, assert response has `transfer-encoding: chunked` (or no `content-length`) and content-type `application/x-ndjson`, body is one JSON line ending in `\n`, parses back to the expected `tools/list` JSON-RPC envelope.
   - `test_partial_response_client_disconnect` — start the streaming response, drop the receiver mid-stream (simulate client disconnect), assert no server panic and the underlying handler future completes or is cancelled cleanly.
   - `test_missing_authorization_header_returns_401` — sentinel test (currently middleware is no-op, so this MUST be `#[ignore]` with a comment "Task 4a will activate" — but the test code itself is written today so Task 4a only flips the ignore + adjusts assertion).

8. **Verify locally.** Run `cargo build -p mnemonic-mcp`, then `cargo test -p mnemonic-mcp -- transport`, then start the server (`STORAGE_MODE=local PAYMENT_MODE=none cargo run -p mnemonic-mcp --release --features local-embed -- --transport http --port 3000`) and curl with `-N` (no buffering) — observe chunked NDJSON.

## Details

**Files:**

`mcp/src/main.rs` — current `mcp_handler` (lines 65-100) returns `Response` built via `Json(...).into_response()`. After this task it returns a `Response<Body>` whose body is `Body::from_stream(stream)` where `stream: impl Stream<Item = Result<Bytes, std::io::Error>> + Send + 'static`. Build the stream from a `tokio::sync::mpsc::channel` (or `futures::stream::once` for the single-frame case) so disconnect cancels cleanly. The router in `run_http` (lines 559-591) gains `.layer(axum::middleware::from_fn(bearer_auth_layer))` on the `/mcp` route — apply via per-route layering (`.route("/mcp", post(mcp_handler).layer(...))`) so other routes are not affected.

`mcp/src/mcp.rs` — append `#[cfg(test)] mod tests { ... }` at the bottom. Build a test `Router` via `Router::new().route("/mcp", post(mcp_handler)).with_state(test_state)` using a minimal `McpState` (use `MockEmbedder` per CLAUDE.md rule #4). Drive with `tower::ServiceExt::oneshot`.

`mcp/Cargo.toml` — add `futures = "0.3"` explicitly under `[dependencies]` (do not rely on axum's transitive). Add `tokio-stream = "0.1"` if not already present. Both are needed for `Body::from_stream` and the test-side stream construction.

**Dependencies:**
- No upstream task dependencies (wave 1).
- Task 4a (OAuth) **depends on** the middleware extension point established here.
- Task 4b (PendingBundles) depends on the streaming response shape for the awaiting-signature reply.

**Edge cases:**
- **Empty body or invalid JSON:** existing behavior returns a JSON-RPC parse error (-32700). Preserve via a single NDJSON error frame, HTTP 400.
- **Tool dispatch panic:** must not poison the stream. Wrap `mcp::handle_request` call in a `tokio::spawn`/`catch_unwind` only if currently used; otherwise rely on tokio task cancellation.
- **CORS:** leave the existing `Any` policy in place — Task 4a tightens to `https://mnemonik.xyz`.
- **Stdio:** `run_stdio` reads `BufReader::new(stdin).lines()` and writes single-line JSON to stdout. Do not refactor — line-delimited is the stdio transport contract per MCP spec.
- **`tools/list` allowlist for Task 4a:** the middleware extension point should make it trivial to whitelist `tools/list` and `initialize` later (Decision 9). Document via comment, do not implement allowlist now.

**Implementation hints:**
- `axum::body::Body::from_stream` accepts `Stream<Item = Result<impl Into<Bytes>, impl Into<BoxError>>>`. Convert each `JsonRpcResponse` to `format!("{json}\n")` then `Bytes::from`.
- For the single-frame current shape, `futures::stream::once(async move { Ok::<_, Infallible>(Bytes::from(line)) })` is the simplest construction.
- The disconnect test can use `tower::ServiceExt::oneshot` and immediately drop the response future — assert no panic in a `tokio::test` runtime (the test passes by completing).
- For `test_missing_authorization_header_returns_401`: write the test against the layered router (with `bearer_auth_layer` attached), `#[ignore]` it today, and add a comment `// Activated by Task 4a — flip ignore + assert 401`.
- Use `MockEmbedder` (test-only embedder per CLAUDE.md architectural rule #4) to construct `McpState` cheaply in tests.
