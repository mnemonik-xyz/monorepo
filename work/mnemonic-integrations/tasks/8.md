# Task 8: Integration tests + MCP Inspector CI

## Required Skills

Before starting, load: `/skill:code-writing` — [SKILL.md](/Users/syi/.claude/skills/code-writing/SKILL.md)

## Description

Add 12 integration test files in `mcp/tests/` covering the Phase-1 surface area introduced by Tasks 1–6 (streamable HTTP, OAuth, deferred-sign flow, owner isolation, rate limit, CORS, allowlist, stdio backward-compat, COSE-via-proxy), and harden `.github/workflows/ci.yml` with three new gates: a pinned `npx @modelcontextprotocol/inspector@0.6.x` validation step (with readiness probe), `cargo audit` for CVE pickup, and YAML-schema validation for `smithery.yaml`.

This task is the assurance backstop for the entire feature. Without it, the new auth/transport/lifecycle code (Tasks 4 + 5) ships without integration coverage and a regression in any of the cross-cutting policies (owner isolation, allowlist, CORS, rate limit, expiry) would only surface in production. The 12 tests are exactly those listed in tech-spec §Testing Strategy → Integration tests.

The `mcp/tests/` directory does not yet exist (`core/tests/` has only unit-level integration files). All 12 files are new. Tests must use `MockEmbedder` (CLAUDE.md architectural rule #4), `STORAGE_MODE=local`, and a deterministic test JWT secret. No real Arweave/Solana traffic.

## What to do

1. **Read current state.** Open `.github/workflows/ci.yml` (4 jobs today: fmt, clippy, test, gitleaks — see code-research §5 for line numbers/commands), `core/src/codec/sign.rs` (`sign_artifact`/`verify_artifact` surface — code-research §8), `core/tests/integration_cbor.rs` (existing roundtrip-test idioms to mirror), and the post-Task-4/5 modules: `mcp/src/oauth.rs` (issued JWT shape, `/oauth/authorize` + `/oauth/token` routes) and `mcp/src/pending.rs` (PendingBundles map, `/api/pending/<id>`, `/api/sign-callback`, 410-on-expiry, per-user 50 cap). Confirm the rate-limit + CORS layering already lives in `mcp/src/main.rs` from Task 1 + Decision 9.

2. **Create the 12 test files** under `mcp/tests/` (one file per test fn, names per the TDD Anchor below). Each file boots a minimal Axum router via `mcp::build_router(McpState { embedder: MockEmbedder, storage_mode: "local", ... })` and drives requests with `tower::ServiceExt::oneshot` or `reqwest` against a `tokio::spawn`-bound port. For tests requiring multi-user JWTs, mint via the helper introduced in Task 4 (`oauth::test_helpers::mint_jwt(sub: &str)` — add it if missing, gated `#[cfg(test)]`).

3. **`oauth_flow.rs`** — drive the full Authorize → Token exchange via two HTTP calls. Build a canonical-CBOR challenge (`state`, `client_id`, `redirect_uri`, `code_challenge`, `nonce`, `exp`), sign with a test Ed25519 keypair, POST `/oauth/authorize`, follow the issued code through `/oauth/token` with `code_verifier`, decode the resulting JWT, assert `iss == "https://mcp.mnemonik.xyz"`, `aud == "mcp.mnemonik.xyz"`, `sub == bs58(pubkey)`, and `exp` is in the future.

4. **`oauth_tool_call.rs`** — reuse helper from #3 to obtain a JWT, then `POST /mcp tools/list` with `Authorization: Bearer <jwt>` and assert exactly 5 tools (`mnemonic_whoami`, `mnemonic_sign_memory`, `mnemonic_recall`, `mnemonic_verify`, `mnemonic_prove_identity`). Then `tools/call mnemonic_sign_memory` with valid args; assert response is `awaiting_signature` with non-empty `correlation_id` and `approve_url` matching `/sign/<uuid-v4>` shape.

5. **`recall_owner_isolation.rs`** — mint two JWTs (user A, user B). User A completes deferred-sign flow twice (sign_memory → fetch pending → sign locally → POST sign-callback) producing 2 attestations; user B does it once. Assert `tools/call mnemonic_recall` with B's JWT returns exactly 1 row whose `owner_pubkey == B.sub`. Assert anonymous `POST /mcp tools/call mnemonic_recall` (no Authorization header) returns HTTP 401 — never 200 with rows. This is the **CRITICAL** test guarding the cross-tenant property.

6. **`stdio_backward_compat.rs`** — `Command::new(env!("CARGO_BIN_EXE_mnemonic-mcp"))` (the pre-built binary, not `cargo run`, to dodge the build-vs-run race) with `EMBED_PROVIDER=mock`, `STORAGE_MODE=local`, `--transport stdio`. Pipe `tools/list`, `tools/call sign_memory`, `tools/call recall` line-delimited JSON-RPC; each request inside `tokio::time::timeout(Duration::from_secs(5))`. Assert all three round-trip cleanly without OAuth.

7. **`roundtrip_cose_via_http_proxy.rs`** — boot a `httpmock`-based proxy that **mutates** the JSON envelope: re-orders object keys alphabetically, normalizes whitespace, and re-encodes via `simd-json`. Send `sign_memory` through it. Verify the `cose_bundle` field (base64 string per Decision 7) is byte-identical after passthrough and `verify_artifact` over its decoded bytes returns `valid = true`. This commits to base64-string encoding as the only proxy-safe transport — see Risks-table R1 mitigation.

8. **`rate_limit_routing.rs`** — boot the actual `mcp::main_router()` (not just the limiter logic) with `tower_governor` configured per Decision 9. Issue 6 `tools/call sign_memory` from the same simulated peer IP within 60s. Assert the 6th returns HTTP 429. This catches `.layer()` ordering regressions where the governor is defined but not wired to `/mcp`.

9. **`cors.rs`** — two preflight `OPTIONS /mcp` requests. First with `Origin: https://mnemonik.xyz` → assert `Access-Control-Allow-Origin: https://mnemonik.xyz` and 204. Second with `Origin: https://evil.example.com` → assert HTTP 403 and no `Access-Control-Allow-Origin` header.

10. **`auth_allowlist.rs`** — `tools/list` and `initialize` JSON-RPC requests **without** Authorization header → assert both return 200 (per Decision 9 allowlist). `tools/call sign_memory` without auth → assert 401. Catches future regressions if someone tightens the allowlist to break MCP discovery.

11. **`deferred_sign_flow.rs`** — full lifecycle: `tools/call sign_memory` → `awaiting_signature`; `GET /api/pending/<id>` with JWT → unsigned bundle returned; sign locally with test keypair; `POST /api/sign-callback` → 200 OK; subsequent `tools/call recall` returns the persisted attestation; second `POST /api/sign-callback` for same id → HTTP 410 Gone (single-use eviction per Decision 12).

12. **`pending_authz.rs`** — user A creates pending bundle. User B (different JWT) calls `GET /api/pending/<userA_id>` → assert 403 Forbidden. User B calls `POST /api/sign-callback` for userA's id → assert 403 Forbidden. Bundle remains intact for user A.

13. **`pending_expiry.rs`** — create pending. Use `tokio::time::pause()` then `tokio::time::advance(Duration::from_secs(301))`. `GET /api/pending/<id>` → 410 Gone; `POST /api/sign-callback` → 410 Gone. Verify bundle is removed from PendingBundles map (assert via debug-only `PendingBundles::contains(id)` helper, gated `#[cfg(test)]`).

14. **`pending_user_cap.rs`** — single JWT. Create 50 pending bundles via 50 `sign_memory` calls (all succeed). 51st `sign_memory` → assert HTTP 429 with a `Retry-After` header.

15. **Update `.github/workflows/ci.yml`** — three additions on top of the existing fmt/clippy/test/gitleaks jobs. (a) `mcp-inspector` job: build mcp binary with `--features local-embed`, start it in background with `EMBED_PROVIDER=mock STORAGE_MODE=local TEST_JWT_SECRET=$(openssl rand -hex 32)`, mint a test JWT via `cargo run -p mnemonic-mcp --bin mint-test-jwt` (helper added in Task 4), poll `curl -fsS http://localhost:3000/health` with 30s timeout (`for i in $(seq 1 30); do ... done`), then `npx @modelcontextprotocol/inspector@0.6.x --validate http://localhost:3000/mcp -H "Authorization: Bearer ${TEST_JWT}"`. (b) `cargo-audit` job: `cargo install cargo-audit --locked` then `cargo audit --deny warnings`. (c) `smithery-schema` job: `pip install yamale && yamale -s scripts/smithery-schema.yaml smithery.yaml` (schema file is small — define inline if not yet present).

16. **Verify locally.** `cargo test -p mnemonic-mcp --tests` runs all 12 integration files. Then trigger CI on a draft PR and confirm the three new jobs are green.

## Details

**Files:**

`mcp/tests/*.rs` — 12 new files, one test fn each. Use `MockEmbedder` per CLAUDE.md rule #4. Construct `McpState` via a `mcp::test_support::mock_state(jwt_secret)` helper (add it under `#[cfg(test)]` in `mcp/src/lib.rs` or a new `mcp/src/test_support.rs` if missing). For tests that need a real binary (`stdio_backward_compat.rs`), use `env!("CARGO_BIN_EXE_mnemonic-mcp")`.

`.github/workflows/ci.yml` — append three jobs after `gitleaks`. The `mcp-inspector` job needs Node (use `actions/setup-node@v4` with `node-version: 20`) and the binary cached from a prior step (or rebuilt with `cargo build --release --features local-embed`). Pin the inspector at `@0.6.x` exactly per spec. The readiness probe is a `for i in $(seq 1 30); do curl -fsS http://localhost:3000/health && break; sleep 1; done` loop. For `cargo-audit`, install via `cargo install cargo-audit --locked` and run `cargo audit --deny warnings`. For `smithery-schema`, `pip install yamale==4.*` and validate `smithery.yaml` (created in Task 5) against `scripts/smithery-schema.yaml` (define schema inline as part of this task — small file describing the expected fields per Smithery docs).

**Dependencies:**
- Depends on **Task 4** (OAuth) — needs `mcp::oauth::test_helpers::mint_jwt` and the `/oauth/*` routes for tests #3, #4, #5, #11–#14.
- Depends on **Task 5** (PendingBundles) — needs `mcp::pending` and `/api/pending/<id>` + `/api/sign-callback` routes for tests #11, #12, #13, #14.
- Independent of Task 6 (webapp) — no UI involvement.
- Task 12 (Pre-deploy QA) executes the full suite produced here as a gate.

**Edge cases:**
- **`tokio::time::pause()` + Axum:** Axum runtime ticks must use the paused clock. Construct the test runtime with `#[tokio::test(start_paused = true)]` for `pending_expiry.rs` so all timers (LRU TTL, JWT exp) participate in `advance()`.
- **`stdio_backward_compat.rs` flake risk:** the binary may take ~200ms to print its readiness banner. Read first stdout line (or wait for a known startup log) before piping the first request, all inside the 5s timeout.
- **`recall_owner_isolation.rs`:** SQLite is shared across users in `STORAGE_MODE=local` — the DB file must be a `tempfile::NamedTempFile` per test to avoid cross-test contamination.
- **CORS preflight in `cors.rs`:** axum sometimes responds 204 (No Content) instead of 200 for OPTIONS — accept either, assert headers only.
- **`cargo audit` exceptions:** if a transitive dep currently has an unfixable advisory (e.g., `solana-sdk` chain), document it in `audit.toml` with `[advisories] ignore = ["RUSTSEC-XXXX-YYYY"]` plus a comment justifying. Do not silence blindly.
- **`smithery.yaml` schema:** Smithery's exact required fields may evolve — schema should cover at minimum `name`, `description`, `endpoint`, `oauth: { authorize_url, token_url, scopes }` per smithery.ai docs at the time of writing.
- **Inspector npx version drift:** `@0.6.x` resolves to whatever 0.6 patch is latest; if the inspector publishes a 0.7 with breaking schema, this job will fail until we bump. Document in `decisions.md` after deploy.

**Implementation hints:**
- Reuse `core/tests/integration_cbor.rs` as the structural template for the proxy test — replace the in-memory roundtrip with an `httpmock::Mock` whose `then()` body re-serializes via `simd_json::to_string(value)`.
- For tests that need to drive the full router, expose `mcp::main_router(state) -> axum::Router` from `mcp/src/main.rs` (refactor `run_http` to call it). Tests then `Router::oneshot()` without booting a TCP listener.
- `mcp::oauth::test_helpers::mint_jwt(sub: &str) -> String` should reuse the same signing key the server is configured with via `TEST_JWT_SECRET` env var; tests set the env before constructing state.
- For `cargo audit`: `audit.toml` lives at repo root next to `Cargo.toml`. Empty `[advisories]` section is fine if zero exceptions exist today.
- For `smithery-schema`: place schema at `scripts/smithery-schema.yaml`, keep it under 30 lines, lock to fields the listing actually uses.
- Run `cargo test -p mnemonic-mcp --tests -- --test-threads=1` if SQLite/port contention causes flakes; ideally each test owns a tempfile DB and an ephemeral port (`tokio::net::TcpListener::bind("127.0.0.1:0")`) so parallel is safe.
