### Focus areas

- **OAuth 2.1 + PKCE correctness** — `code_verifier` validated against stored `code_challenge` via S256 (no `plain` fallback), `state` bound to session for CSRF, authorization codes are atomically single-use (no TOCTOU between check and consume), expired codes rejected at the 60s TTL boundary, S256-only enforced server-side.
- **JWT issuance** — HS256 with fixed `alg`, server rejects `alg=none` and `alg=RS*` smuggle attempts, `iss` and `aud` claims validated on every protected request, `sub` integrity preserved end-to-end, no JWT or signing key in any `tracing`/`println` line.
- **MCP_JWT_SECRET handling** — read from env only, never logged at any level, never in error messages, file mode `0600` if persisted to disk, no default fallback that lets the server start without it.
- **Bearer middleware allowlist** — exactly `/oauth/*`, `/health`, JSON-RPC `initialize`, and `tools/list` are anonymous; `tools/call` and every other JSON-RPC method require a valid JWT. No fail-open path on middleware errors (must reject, not pass).
- **CORS** — exact origin `https://mnemonik.xyz` (no `Any` / `*` wildcard), `allow_credentials` only if intentional, preflight does not echo arbitrary `Origin`.
- **Sign-callback validation** — `signer_pubkey == jwt.sub` asserted before persistence, COSE_Sign1 byte-level signature verified (not just structural parse), `content_hash` recomputed from canonical CBOR and matched, pending bundle atomically evicted on success to prevent replay.
- **localStorage keypair / XSS surface** — full CSP meta tag includes `default-src`, `script-src`, `connect-src`, `style-src`, `img-src`, `font-src`, `frame-ancestors 'none'`, `base-uri 'self'`, `object-src 'none'`, `form-action 'self'`. `import_keypair_json` validates 32-byte secret + 32-byte public components and rejects malformed input. Stored keypair encrypted with AES-GCM under a passphrase-derived key (Argon2id or PBKDF2 with sane params).
- **PendingBundles DoS** — bounded by LRU cap (10000) AND TTL (300s) AND per-user cap (50). GET on a pending bundle is authorized against `jwt.sub` and returns 403 (not 404) on owner mismatch to avoid enumeration via timing.
- **Rate limiting** — per-IP limiter applied to `/mcp` and `/oauth/*`, returns 429 with `Retry-After` header. `tower_governor` and `governor` versions resolve to a single major version each (no duplicate majors in `Cargo.lock`); compatibility with `tower_governor = "0.8"` and `governor = "0.8"`.
- **Smithery yaml** — no email, no API key, no internal hostname, no JWT secret, no operator PII in the public listing.
- **nginx server-block** — HSTS header present with `includeSubDomains` and `preload`, TLS 1.0/1.1 explicitly disabled (`ssl_protocols TLSv1.2 TLSv1.3`), default `error_page` does not leak nginx version or upstream banner, `server_tokens off`.
- **Dependencies** — `cargo audit` runs in `.github/workflows/ci.yml` and fails the build on advisories; security-critical deps (`jsonwebtoken`, `tower_governor`, `governor`, `axum`, `oauth2`-related crates if any) pinned with `=` rather than caret ranges.
- **A04 Insecure Design** — assess threat-model gaps in deferred-sign flow (e.g., `approve_url` confusion attacks where a malicious site spoofs the approval URL, content-preview spoofing where the displayed preview differs from the bytes actually signed, missing user-intent confirmation between MCP-initiated bundle and webapp signing).
- **A06 Vulnerable and Outdated Components** — confirm `cargo audit` step in CI passes; review pinned versions (`jsonwebtoken`, `tower_governor`, `governor`, `axum`, `oauth2`-related crates, `wasm-bindgen`, frontend deps) for known advisories at audit time.
