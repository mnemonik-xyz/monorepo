# Task 5: Free/paid fork keys off `WriteMode`, per-write

## Description

Make "personal memory is free" a structural property of the code path. The
paywall fires iff the resolved write mode is `Participate`; `Local` writes never
touch `payment.rs`.

## What to do

1. **Replace the boot-time paywall condition** in `mcp/src/mcp.rs:424`. Today:
   `is_sign_memory && state.payment_mode != "none" && state.storage_mode != "local"`.
   New: `is_sign_memory && resolved_mode == WriteMode::Participate && state.payment_mode != "none"`.
   (`payment_mode` now governs *how* a participate write is paid, not whether the
   process is in a paid mode.)
2. **Cost recording** in `tools.rs:367` (`if storage_mode != "local"`): gate on
   `matches!(mode, WriteMode::Participate)` instead.
3. Confirm `Local` writes do not call `payment::charge`/`record_attestation_cost`
   and incur zero cost regardless of `payment_mode`.

## Acceptance Criteria

- [ ] Paywall gate evaluates per-call against `WriteMode::Participate`.
- [ ] A `local` write on a `payment_mode != "none"` server is free and bypasses payment.rs entirely.
- [ ] A `participate` write on a `payment_mode != "none"` server is charged exactly as the old `full` path was.
- [ ] Existing payment tests still pass; add a test asserting `local` is free under each `payment_mode`.
