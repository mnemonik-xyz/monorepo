# Task 1: `WriteMode` enum in `mnemonic-core`

## Description

Introduce the typed per-write mode that replaces stringly-typed `storage_mode`
threading. Pure type, no I/O. Smallest possible first diff.

## What to do

1. **Create `core/src/storage/mode.rs`:**
   - `pub enum WriteMode { Local, Participate }` with `#[derive(Clone, Copy, Debug, PartialEq, Eq)]`.
   - `impl WriteMode`: `from_str(&str) -> Option<Self>` accepting `"local"` →
     `Local`, `"participate"` → `Participate` (case-insensitive); `as_str(&self)`
     returning the canonical lowercase string; `Default` = `Local`.
   - Doc comment: `Local` = free, self-hosted, default; `Participate` = anchored
     + publicly published, paid, delivery confirmed by recall+verify.
2. **Re-export** from `core/src/storage/mod.rs` (`pub use mode::WriteMode;`) and
   confirm it surfaces via `core/src/lib.rs` (`storage` is already `pub mod`).
3. **No behavior change** anywhere yet — nothing consumes the enum in this task.

## Acceptance Criteria

- [ ] `core/src/storage/mode.rs` exists with `WriteMode` + `from_str`/`as_str`/`Default`.
- [ ] Re-exported; `mnemonic_core::storage::WriteMode` resolves.
- [ ] Unit tests: round-trip `from_str`/`as_str` for both variants; unknown string → `None`; `Default::default() == Local`.
- [ ] `cargo build -p mnemonic-core` and `cargo test -p mnemonic-core` pass.
- [ ] No edits to `mcp/`.
