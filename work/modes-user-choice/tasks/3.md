# Task 3: Delivery guarantee — recall+verify roundtrip; demote-to-local on failure; refund; DoS guard

## Description

Wrap the participate branch of `sign_memory_inline` in a delivery-confirmation
step (Arweave re-fetch with wall-clock retry budget → `verify_cose` →
in-process `recall`). On success: row tagged `participate`, charge recorded,
`delivery_receipt` returned. On failure: row tagged `local`, payment refunded,
`-32011 DeliveryNotConfirmed` returned, **zero charge**. Add an outcome-based
DoS guard keyed on `api_key_hash` consulted BEFORE any chain write to prevent
margin bleed by induced repeated failures.

## What to do

1. **Refetch helper** in `mcp/src/tools.rs` (private):
   - `async fn arweave_refetch_with_budget(arweave: &ArweaveClient, tx: &str,
     timeout: Duration) -> Result<Vec<u8>>` — exponential backoff with
     `tokio::time::sleep`, capped by wall-clock budget; returns the bytes on
     success or `Err` on budget exhaustion. Start delay 200ms, factor 2.0,
     max single delay 2s. No fixed attempt count.

2. **`mcp/src/config.rs`:** add
   - `delivery_refetch_timeout_secs: u64` (env `MNEMONIC_DELIVERY_REFETCH_TIMEOUT_SECS`, default `15`).
   - `delivery_quota_threshold: u32` (env `MNEMONIC_DELIVERY_QUOTA_THRESHOLD`, default `5`).
   - `delivery_quota_window_secs: u64` (env `MNEMONIC_DELIVERY_QUOTA_WINDOW_SECS`, default `60`).
   - `delivery_quota_evict_interval_secs: u64` (env `MNEMONIC_DELIVERY_QUOTA_EVICT_SECS`, default `30`).

3. **DoS guard `RefundsBySubject` in `mcp/src/payment.rs`:**
   - `pub struct RefundsBySubject { inner: Arc<DashMap<String, SlidingWindowCounter>>, window: Duration, threshold: u32 }`.
   - Key = `api_key_hash` (a `blake3` digest of the bearer api_key, hex-encoded).
     Computed once at the entry of the participate path; pass that hash
     through to refund + counter. NEVER store the raw `api_key`.
   - `SlidingWindowCounter` records timestamps within `window`; methods:
     - `record(now)` — push timestamp, drop expired.
     - `count(now) -> u32` — number of non-expired timestamps.
   - `RefundsBySubject::is_over(&self, subject: &str) -> bool` — returns
     `count(now) >= threshold`, holding the shard guard briefly (no `.await`
     while held — extends Decision 8 of tech-spec).
   - `RefundsBySubject::record_failure(&self, subject: &str)` — increment.
   - **Bounded eviction:** spawn a background task in `McpState::new` running
     every `quota_evict_interval_secs` that drops entries whose window is
     empty for `2 * window`. Holds shard guards briefly per shard.
   - Plumbed into `McpState` so handlers can consult it.

4. **Participate-entry quota check (in `mcp/src/mcp.rs::mcp_handler`):**
   - Compute `subject = blake3(api_key).to_hex()` from the Bearer token (when
     present; for stdio paths this guard is a no-op since stdio is local-only
     trust).
   - If `state.refunds_by_subject.is_over(&subject)` → return JSON-RPC
     `-32011` with `data: { kind: "DeliveryQuotaExceeded", window_secs,
     threshold }`. Do NOT call `check_payment`, do NOT enter
     `sign_memory_inline`. Increment a Prometheus counter
     `mnemonic_delivery_quota_short_circuit_total` (label set:
     `{ }` — no high-cardinality labels).

5. **Participate flow in `sign_memory_inline`:**
   - After `solana.write_memo(...).await?` returns the `sol_tx`:
     - call `arweave_refetch_with_budget(arweave, &ar_tx, timeout)`. On `Err`
       → go to "delivery failure" branch (stage = `refetch`).
     - call `verify_cose(&refetched_bytes, Some(&content_hash), &sol_tx,
       Some(&ar_tx))` (existing helper, sync). If `Err` or
       result.is_invalid → "delivery failure" branch (stage = `verify`).
     - call `recall` against the just-written `content_hash` (in-process,
       not over HTTP). If it does not return our `attestation_id` as a
       top result → "delivery failure" branch (stage = `recall`).
   - **Success branch (short critical section):**
     `{ let store = store.lock().unwrap(); store.save_attestation(...,
     WriteMode::Participate, &embedding)?; payment::record_attestation_cost(
     &store, ...)?; }` — lock dropped before `.await` resumes.
   - **Failure branch (short critical section):**
     `{ let store = store.lock().unwrap(); store.save_attestation(...,
     WriteMode::Local, &embedding)?; }` — write the local-tagged row, drop the
     lock. Then **outside the lock**:
     `payment::refund_balance(&state.store, &api_key, charge_micro_usdc,
     &format!("delivery_not_confirmed: {attestation_id}"))?;` — if this fails,
     insert an audit row in `payment_events`:
     `event_kind='refund_failed'`, columns `{api_key_hash, attestation_id,
     reason, occurred_at}` (NO raw `api_key`, NO payload bytes).
     Record failure in `RefundsBySubject` via `record_failure(&subject)`.
     Increment `mnemonic_delivery_not_confirmed_total{stage}` Prometheus
     counter.
     Return JSON-RPC `-32011 DeliveryNotConfirmed` with
     `data: { kind: "DeliveryNotConfirmed", arweave_tx, solana_tx, stage,
     row_demoted_to: "local", attestation_id }`.

6. **Success envelope additions** in the participate branch:
   - `"write_mode": "participate"`.
   - `"delivery_receipt": { "arweave_tx": ar_tx, "solana_tx": sol_tx,
     "recall_verified_at": now_iso8601() }` — server-attested; document the
     trust model is per tech-spec §"Trust model for `recall_verified_at`".

7. **`payment_events` schema extension** in `core/src/storage/sqlite.rs`:
   - Idempotent migration helper `migrate_payment_events_refund_failed` (or
     add to the existing `migrate_payment_events_*` helper) that ensures the
     table has the columns needed: `event_kind TEXT NOT NULL DEFAULT 'charge'`,
     `attestation_id TEXT`, `reason TEXT`. Pre-existing rows: event_kind
     defaults to `'charge'`.
   - New API on the storage layer:
     `fn record_refund_failed(&self, api_key_hash: &str, attestation_id: &str,
     reason: &str, occurred_at: &str) -> Result<()>`.

8. **Integration tests** in `mcp/tests/delivery_guarantee.rs` (new file). Uses
   the existing `arlocal` + `solana-test-validator` harness and httpmock
   pattern from `core/src/arweave/mod.rs::new_for_test`:
   - `happy_path`: real arlocal, anchor succeeds, recall+verify succeeds → row
     `write_mode='participate'`, `delivery_receipt` present,
     `attestation_costs` row written, no `payment_events` audit row, balance
     deducted by the live price.
   - `demotion_on_refetch_failure` (PAYMENT_MODE=balance): single-server
     `httpmock` returning corrupted GET bytes; assertions: JSON-RPC `-32011`
     with `stage: "refetch"`, row `write_mode='local'`, no
     `attestation_costs` row, **balance returns to pre-call value** (refund-
     release assertion), Prometheus counter `…not_confirmed_total{stage="refetch"}`
     incremented.
   - `demotion_on_verify_failure`: httpmock returns *different valid* COSE
     bytes (signed with another key) → `stage: "verify"`.
   - `demotion_on_x402` (PAYMENT_MODE=x402): same demotion path, additionally
     asserts the x402 nonce is **not** marked consumed in `x402_nonces` — the
     caller can retry with the same payment.
   - `quota_exceeded`: induce 5 consecutive demotions for one
     `api_key_hash`; the 6th `participate` call returns `-32011` with
     `kind: "DeliveryQuotaExceeded"` **before** any Arweave/Solana call
     (asserted by *zero* httpmock invocations on the 6th call).
   - `refund_failure_writes_audit_row`: stub the refund path to fail; assert
     a `payment_events { event_kind: 'refund_failed', api_key_hash, ... }`
     row exists with NO `api_key` or payload bytes in any column.

## Acceptance Criteria

- [ ] Successful `participate` returns `delivery_receipt`; row
      `write_mode='participate'`; `attestation_costs` row written.
- [ ] Refetch failure → row `write_mode='local'`; no `attestation_costs` row;
      balance restored to pre-call value (or x402 nonce reusable); `-32011`
      with `stage: "refetch"`.
- [ ] Verify failure path covered (stage: `verify`).
- [ ] Recall failure path covered (stage: `recall`).
- [ ] Quota guard: after threshold demotions for one `api_key_hash`, next
      participate request short-circuits with `kind:
      "DeliveryQuotaExceeded"`; zero Arweave/Solana calls occur in that
      request (asserted by absence of httpmock invocations).
- [ ] Quota window timestamps and threshold come from env vars
      (`MNEMONIC_DELIVERY_QUOTA_*`); changing them in the test harness
      changes behavior.
- [ ] Refund-itself failure writes a `payment_events` row with
      `event_kind='refund_failed'` carrying ONLY
      `{api_key_hash, attestation_id, reason, occurred_at}` — no raw
      `api_key`, no `content_preview`, no `cose_bytes`.
- [ ] No `.await` while a `SqliteStore` mutex OR a `DashMap` shard guard is
      held (covered by an inspection comment and a static-analysis lint or
      reviewer note).
- [ ] `cargo test -p mnemonic-mcp delivery_guarantee --no-fail-fast` green.
- [ ] `cargo test -p mnemonic-mcp --no-fail-fast` green.
- [ ] `cargo clippy -p mnemonic-mcp --all-targets -- -D warnings` clean.

## TDD Anchor

First test (in `mcp/tests/delivery_guarantee.rs`):

```rust
#[tokio::test]
async fn refetch_failure_demotes_row_and_refunds_balance() {
    let server = TestServer::builder()
        .storage_mode("full")
        .payment_mode("balance")
        .arweave_mock(MockArweave::corrupted_get())  // anchor succeeds, GET returns wrong bytes
        .build().await;

    let pre_balance = server.balance_for(API_KEY).await;
    let resp = server.call_tool("mnemonic_sign_memory",
        json!({ "content": "x", "mode": "participate" })).await;

    let err = resp.error.expect("expected error");
    assert_eq!(err.code, -32011);
    let data = err.data.as_object().unwrap();
    assert_eq!(data["kind"], "DeliveryNotConfirmed");
    assert_eq!(data["stage"], "refetch");
    assert_eq!(data["row_demoted_to"], "local");

    // Row exists, tagged local; no charge; balance restored.
    let row = server.fetch_attestation(&data["attestation_id"].as_str().unwrap()).await;
    assert_eq!(row.write_mode, "local");
    assert!(server.attestation_costs_count().await == 0);
    assert_eq!(server.balance_for(API_KEY).await, pre_balance);
}
```
