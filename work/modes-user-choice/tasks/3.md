# Task 3: `whoami` advertises the mode envelope

## Description

Let a client discover what a server offers before it writes. `whoami` reports the
supported modes, the default, and the per-artifact participate cost.

## What to do

1. **Edit `mcp/src/tools.rs::whoami`:** it already takes `storage_mode: &str`.
   Extend its signature to also take `&Config` (or the three derived values:
   `allow_participate`, `default_write_mode`, `sign_memory_cost_micro_usdc`).
   Add to the returned JSON:
   - `"supported_modes"`: `["local"]` if `!allow_participate`, else `["local", "participate"]`.
   - `"default_mode"`: `default_write_mode`.
   - `"participate_cost_micro_usdc"`: the floor cost (only meaningful when
     `allow_participate`; emit `null` otherwise).
2. **Update the caller** in `mcp/src/mcp.rs` (the `tools::whoami(...)` dispatch)
   to pass the new args from `McpState`/`Config`.
3. Keep the existing `storage_mode` field in the output for back-compat.

## Acceptance Criteria

- [ ] `whoami` output includes `supported_modes`, `default_mode`, `participate_cost_micro_usdc`.
- [ ] Local-only server ⇒ `supported_modes == ["local"]`, cost `null`.
- [ ] Anchoring server ⇒ `supported_modes == ["local","participate"]`, numeric cost.
- [ ] Existing `whoami` test(s) updated; `cargo test -p mnemonic-mcp` passes.

## Files

**Read:** `mcp/src/tools.rs` (whoami), `mcp/src/mcp.rs` (whoami dispatch), `mcp/src/config.rs`
**Modify:** `mcp/src/tools.rs`, `mcp/src/mcp.rs`
