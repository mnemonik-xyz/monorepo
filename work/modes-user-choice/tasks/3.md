# Task 3: Delivery guarantee — recall+verify roundtrip; demote-to-local on failure; refund; DoS guard

## Description

Wrap the participate branch of `sign_memory_inline` in a delivery-confirmation
step (Arweave re-fetch with wall-clock retry budget → `verify_cose` →
in-process `recall`). On success: row tagged `participate`, charge recorded,
`delivery_receipt` returned. On failure: row tagged `local`, payment refunded,
`-32011 DeliveryNotConfirmed` returned, **zero charge**. Add an outcome-based
DoS guard keyed on `api_key_hash` consulted BEFORE any chain write to prevent
margin bleed by induced repeated failures.

## What to do

1. **Refetch helper** in `mcp/src/tools.rs` (private):
   - `async fn arweave_refetch_with_budget(arweave: &ArweaveClient, tx: &str,
     timeout: Duration) -> Result<Vec<u8>>` — exponential backoff with
     `tokio::time::sleep`, capped by wall-clock budget; returns the bytes on
     success or `Err` on budget exhaustion. Start delay 200ms, factor 2.0,
     max single delay 2s. No fixed attempt count.

2. **`mcp/src/config.rs`:** add
   - `delivery_refetch_timeout_secs: u64` (env `MNEMONIC_DELIVERY_REFETCH_TIMEOUT_SECS`, default `15`).
   - `delivery_quota_threshold: u32` (env `MNEMONIC_DELIVERY_QUOTA_THRESHOLD`, default `5`).
   - `delivery_quota_window_secs: u64` (env `MNEMONIC_DELIVERY_QUOTA_WINDOW_SECS`, default `60`).
   - `delivery_quota_evict_interval_secs: u64` (env `MNEMONIC_DELIVERY_QUOTA_EVICT_SECS`, default `30`).

3. **DoS guard `RefundsBySubject` in `mcp/src/payment.rs`:**
   - `pub struct RefundsBySubject { inner: Arc<DashMap<String, SlidingWindowCounter>>, window: Duration, threshold: u32 }`.
   - Key = `api_key_hash` (a `blake3` digest of the bearer api_key, hex-encoded).
     Computed once at the entry of the participate path; pass that hash
     through to refund + counter. NEVER store the raw `api_key`.
   - `SlidingWindowCounter` records timestamps within `window`; methods:
     - `record(now)` — push timestamp, drop expired.
     - `count(now) -> u32` — number of non-expired timestamps.
   - `RefundsBySubject::is_over(&self, subject: &str) -> bool` — returns
     `count(now) >= threshold`, holding the shard guard briefly (no `.await`
     while held — extends Decision 8 of tech-spec).
   - `RefundsBySubject::record_failure(&self, subject: &str)` — increment.
   - **Bounded eviction:** spawn a background task with `tokio::spawn` from
     `mcp/src/main.rs::run_http` AFTER the `McpState` struct literal is
     constructed and wrapped in `Arc` (there is no `McpState::new` — the
     struct is built as a literal in `run_http` and `build_test_state`).
     The task runs every `quota_evict_interval_secs` and drops entries
     whose window has been empty for `2 * window`. Holds shard guards
     briefly per shard, never across `.await`.
   - Plumbed into `McpState` so handlers can consult it.

4. **Participate-entry quota check (in `mcp/src/mcp.rs::mcp_handler`):**
   - Compute `subject = blake3(api_key).to_hex()` from the Bearer token (when
     present; for stdio paths this guard is a no-op since stdio is local-only
     trust).
   - If `state.refunds_by_subject.is_over(&subject)` → return JSON-RPC
     `-32011` with `data: { kind: "DeliveryQuotaExceeded", window_secs,
     threshold }`. Do NOT call `check_payment`, do NOT enter
     `sign_memory_inline`. Increment a Prometheus counter
     `mnemonic_delivery_quota_short_circuit_total` (label set:
     `{ }` — no high-cardinality labels).

5. **Participate flow in `sign_memory_inline`:**
   - After `solana.write_memo(...).await?` returns the `sol_tx`:
     - call `arweave_refetch_with_budget(arweave, &ar_tx, timeout).await`.
       On `Err` → go to "delivery failure" branch (stage = `refetch`).
     - call `verify_cose(&refetched_bytes, Some(&content_hash),
       Some(&sol_tx), &ar_tx)` (existing helper signature: `cose_bytes:
       &[u8], expected_hash: Option<&str>, solana_tx: Option<&str>,
       arweave_tx: &str`; returns `anyhow::Result<serde_json::Value>`).
       On `Err` → failure branch (stage = `verify`). On `Ok(result)`: read
       `result["status"]` (string `"verified"` / `"tampered"` /
       `"not_found"`); anything other than `"verified"` → failure branch
       (stage = `verify`).
     - call `tools::recall` (in-process, not over HTTP) against
       `content_hash`. If the recall list does NOT include our
       `attestation_id` → failure branch (stage = `recall`).
   - **Success branch — one short critical section:**
     ```rust
     {
         let store = store.lock().unwrap();
         store.save_attestation(..., WriteMode::Participate, &embedding)?;
         payment::record_attestation_cost(&store, ...)?;
     } // mutex dropped here; no `.await` while held
     ```
   - **Failure branch — one short critical section, refund OUTSIDE:**
     ```rust
     let demoted_id = {
         let store = store.lock().unwrap();
         store.save_attestation(..., WriteMode::Local, &embedding)?;
         attestation_id.clone()
     };
     // outside lock; .await safe
     // state.store is Arc<Mutex<SqliteStore>>; refund_balance takes
     // &SqliteStore — match the existing call-site pattern in
     // mcp/src/mcp.rs (lock briefly, drop before any later await).
     let refund_res = {
         let store = state.store.lock().unwrap();
         payment::refund_balance(
             &store, &api_key, charge_micro_usdc,
             &format!("delivery_not_confirmed: {demoted_id}"),
         )
     };
     if refund_res.is_err() {
         let store = state.store.lock().unwrap();
         payment::record_refund_failed(
             &store, &api_key_hash, &demoted_id,
             "refund-itself-failed", &now_iso8601(),
         ).ok();   // best-effort audit
     }
     state.refunds_by_subject.record_failure(&api_key_hash);
     metrics::counter!("mnemonic_delivery_not_confirmed_total",
                       "stage" => stage_label).increment(1);
     // Return JSON-RPC -32011 DeliveryNotConfirmed { kind, arweave_tx,
     // solana_tx, stage, row_demoted_to: "local", attestation_id }.
     ```
   - **`record_refund_failed` API lives in `mcp/src/payment.rs`** (per the
     project's hard architectural rule: all payment methods live in
     `payment.rs`, never in `core/`). Its body inserts a `payment_events`
     row with `event_type='refund_failed'`, `tx_sig=NULL`, allow-list
     columns `{api_key, amount_micro_usdc, event_type, description,
     created_at}` populated as
     `api_key = api_key_hash` (NOT the raw key — pass the hash as the
     identifier), `amount_micro_usdc = 0` (not an actual payment),
     `description = format!("{attestation_id} | {reason}")`. Only the
     schema migration (if any) lives in `core/src/storage/sqlite.rs`.

6. **Success envelope additions** in the participate branch:
   - `"write_mode": "participate"`.
   - `"delivery_receipt": { "arweave_tx": ar_tx, "solana_tx": sol_tx,
     "recall_verified_at": now_iso8601() }` — server-attested; document the
     trust model is per tech-spec §"Trust model for `recall_verified_at`".

7. **No new `payment_events` schema work needed** — the existing schema
   (see `core/src/storage/sqlite.rs` `CREATE TABLE payment_events`) already
   has `event_type`, `tx_sig` (nullable), `description` (default `''`),
   `created_at`, `amount_micro_usdc`. We reuse those columns; the
   `event_type='refund_failed'` value is just a new enumerant. The
   `attestation_id + reason` payload goes into the existing `description`
   column as a `"{attestation_id} | {reason}"` format string (PII allow-
   list pinned — no raw `api_key`, no payload bytes, no preview). The
   `api_key` column on the row carries `api_key_hash`, not the raw key.
   No core/sqlite migration needed for this task.

8. **Integration tests** in `mcp/tests/delivery_guarantee.rs` (new file).
   Uses the T2 `mcp/tests/_helpers/` test harness (extended in this task
   to expose `MockArweave::corrupted_get()` and balance/attestation
   accessors) plus the existing `arlocal` + `solana-test-validator`
   harness, plus the httpmock pattern from
   `core/src/arweave/mod.rs::new_for_test`:
   - `happy_path`: real arlocal, anchor succeeds, recall+verify succeeds → row
     `write_mode='participate'`, `delivery_receipt` present,
     `attestation_costs` row written, no `payment_events` audit row, balance
     deducted by the live price.
   - `demotion_on_refetch_failure` (PAYMENT_MODE=balance): single-server
     `httpmock` returning corrupted GET bytes; assertions: JSON-RPC `-32011`
     with `stage: "refetch"`, row `write_mode='local'`, no
     `attestation_costs` row, **balance returns to pre-call value** (refund-
     release assertion), Prometheus counter `…not_confirmed_total{stage="refetch"}`
     incremented.
   - `demotion_on_verify_failure`: httpmock returns *different valid* COSE
     bytes (signed with another key) → `stage: "verify"`.
   - `demotion_on_x402` (PAYMENT_MODE=x402): same demotion path, additionally
     asserts the x402 nonce is **not** marked consumed in `x402_nonces` — the
     caller can retry with the same payment.
   - `quota_exceeded`: induce 5 consecutive demotions for one
     `api_key_hash`; the 6th `participate` call returns `-32011` with
     `kind: "DeliveryQuotaExceeded"` **before** any Arweave/Solana call
     (asserted by *zero* httpmock invocations on the 6th call).
   - `refund_failure_writes_audit_row`: stub the refund path to fail; assert
     a `payment_events { event_type: 'refund_failed', api_key_hash, ... }`
     row exists with NO `api_key` or payload bytes in any column.

## Acceptance Criteria

- [ ] Successful `participate` returns `delivery_receipt`; row
      `write_mode='participate'`; `attestation_costs` row written.
- [ ] Refetch failure → row `write_mode='local'`; no `attestation_costs` row;
      balance restored to pre-call value (or x402 nonce reusable); `-32011`
      with `stage: "refetch"`.
- [ ] Verify failure path covered (stage: `verify`).
- [ ] Recall failure path covered (stage: `recall`).
- [ ] Quota guard: after threshold demotions for one `api_key_hash`, next
      participate request short-circuits with `kind:
      "DeliveryQuotaExceeded"`; zero Arweave/Solana calls occur in that
      request (asserted by absence of httpmock invocations).
- [ ] Quota window timestamps and threshold come from env vars
      (`MNEMONIC_DELIVERY_QUOTA_*`); changing them in the test harness
      changes behavior.
- [ ] Refund-itself failure writes a `payment_events` row with
      `event_type='refund_failed'` carrying ONLY
      `{api_key_hash, attestation_id, reason, occurred_at}` — no raw
      `api_key`, no `content_preview`, no `cose_bytes`.
- [ ] No `.await` while a `SqliteStore` mutex OR a `DashMap` shard guard is
      held (covered by an inspection comment and a static-analysis lint or
      reviewer note).
- [ ] `cargo test -p mnemonic-mcp delivery_guarantee --no-fail-fast` green.
- [ ] `cargo test -p mnemonic-mcp --no-fail-fast` green.
- [ ] `cargo clippy -p mnemonic-mcp --all-targets -- -D warnings` clean.

## TDD Anchor

First test — wired against the bare primitives that already exist
(`httpmock::MockServer`, `ArweaveClient::new_for_test`, the
`build_test_state()` pattern). Avoids depending on the `_helpers/`
harness that T2 introduces and on `MockArweave::corrupted_get()` that this
very task introduces — chicken-and-egg avoided.

Inside `mcp/src/mcp.rs` `#[cfg(test)] mod tests` (or as a sibling
`#[cfg(test)] mod delivery_tests` co-located in mcp.rs while iterating;
once green, file moves to `mcp/tests/delivery_guarantee.rs`):

```rust
#[tokio::test]
async fn refetch_failure_demotes_row_and_refunds_balance() {
    // 1) Stand up a single httpmock for arweave; anchor PUT returns 200,
    //    GET returns wrong bytes (induces verify_cose hash mismatch).
    let mock = httpmock::MockServer::start();
    mock.mock(|when, then| {
        when.method(httpmock::Method::POST).path_contains("/tx");
        then.status(200).body(r#"{"id":"AR_TX_1"}"#);
    });
    mock.mock(|when, then| {
        when.method(httpmock::Method::GET).path_contains("AR_TX_1");
        then.status(200).body(b"not-the-cose-bytes-you-anchored");
    });

    // 2) Build state with storage_mode=full, payment_mode=balance, arweave
    //    pointing at the mock.
    let state = build_test_state_with_overrides(|cfg| {
        cfg.storage_mode = "full".into();
        cfg.payment_mode = "balance".into();
        cfg.arweave_url   = mock.base_url();
    });
    seed_balance(&state, API_KEY, 1_000_000_micro_usdc).await;
    let pre_balance = balance_of(&state, API_KEY).await;

    // 3) Issue the participate call via the existing router pattern.
    let app = build_test_router(state.clone());
    let body = serde_json::json!({
        "jsonrpc":"2.0","id":1,"method":"tools/call",
        "params":{"name":"mnemonic_sign_memory",
                  "arguments":{"content":"x","mode":"participate"}}});
    let req = Request::builder()
        .method("POST").uri("/mcp")
        .header("content-type","application/json")
        .header("authorization", format!("Bearer {}", mint_jwt_for_tests()))
        .body(Body::from(serde_json::to_vec(&body).unwrap())).unwrap();
    let resp = app.oneshot(req).await.unwrap();
    let (_s, _h, bytes) = collect_body(resp).await;
    let envelope: serde_json::Value = serde_json::from_slice(&bytes).unwrap();

    // 4) Assert the typed delivery-not-confirmed shape.
    let err = envelope["error"].as_object().expect("expected JSON-RPC error");
    assert_eq!(err["code"], -32011);
    let data = err["data"].as_object().unwrap();
    assert_eq!(data["kind"], "DeliveryNotConfirmed");
    assert_eq!(data["stage"], "refetch"); // or "verify" depending on order
    assert_eq!(data["row_demoted_to"], "local");

    // 5) Row tagged local, no cost row, balance restored.
    let store = state.store.lock().unwrap();
    let row = store.find_attestation(data["attestation_id"].as_str().unwrap())
                   .unwrap().unwrap();
    assert_eq!(row.write_mode, "local");
    assert_eq!(store.count_attestation_costs().unwrap_or(0), 0);
    drop(store);
    assert_eq!(balance_of(&state, API_KEY).await, pre_balance);
}
```

`build_test_state_with_overrides`, `seed_balance`, `balance_of`,
`find_attestation`, `count_attestation_costs` are tiny test helpers — add
them in this task as private test-only extensions of the existing
`build_test_state` pattern (NOT as part of the production `SqliteStore`
API). The `_helpers/` harness from T2 (already merged by Wave 3) is the
public reusable layer; this anchor uses the more primitive entry points
to verify smallest-possible behavior shift.
