# Task 2: Per-request `mode` field, paywall reframing, `whoami` envelope, golden compat fixture

## Description

Add the optional `mode` field to `mnemonic_sign_memory` and a single resolver
function that drives both the paywall gate and the value persisted in
`write_mode`. Reroute the paywall to fire on resolved `WriteMode::Participate`
(not env-vars). Extend `whoami` to return the discoverability envelope
(`supported_modes`, `default_mode`, `participate_cost`). Emit `-32010
UnsupportedMode` (typed) on a request the server can't serve; `-32602
InvalidParams` on malformed `mode`. Land a golden-fixture test pinning the
mode-absent response shape so the shipped extension's Cloud-tier path is
regression-guarded.

## What to do

1. **Mode resolver (single source of truth) in `mcp/src/tools.rs`:**
   - New `pub(crate) fn resolve_write_mode(input_mode: Option<&serde_json::Value>,
     env_storage_mode: &str) -> Result<WriteMode, JsonRpcError>`:
     - `None` (key absent) → fallback to env: `local` iff
       `env_storage_mode == "local"`, else `Participate`.
     - `Some(Value::String("local"))` → `WriteMode::Local`.
     - `Some(Value::String("participate"))` → `WriteMode::Participate`.
     - **Everything else** (`null`, non-string, `""`, `" "`, `"Local"`,
       `"PARTICIPATE"`, `"unknown"`, …) → `Err(invalid_params("mode",
       received_verbatim))`.
   - `invalid_params` returns the standard `-32602` shape with
     `data: { field: "mode", received: <verbatim> }`.

2. **`mcp/src/mcp.rs::mcp_handler`:**
   - Before the paywall gate, when `req.method == "tools/call"` and tool name
     is `mnemonic_sign_memory`, extract `params.arguments.mode` and call
     `resolve_write_mode(...)`. Propagate any `Err` immediately as the
     JSON-RPC error response.
   - **Paywall gate change:** replace
     `if is_sign_memory && state.payment_mode != "none" && state.storage_mode != "local"`
     with `if is_sign_memory && resolved_mode == WriteMode::Participate &&
     state.payment_mode != "none"`. Local writes never reach `check_payment`.
   - Thread `resolved_mode` into the `tools::sign_memory(...)` call.

3. **`mcp/src/tools.rs::sign_memory` + `sign_memory_inline`:**
   - Add `write_mode: WriteMode` to the signature (replacing the `storage_mode:
     &str` parameter for routing decisions; keep `storage_mode` available only
     for legacy logging/envelope echo since `whoami` still surfaces it).
   - Branch on `write_mode == WriteMode::Local` for the synthetic-id /
     no-anchor path. Branch on `WriteMode::Participate` for the
     Arweave+Solana write path. Cost-recording fires only on `Participate`.
   - Pass `write_mode` through to `save_attestation`.
   - Add a top-of-function check: if `write_mode == Participate` and the server
     does NOT support it (`!state.envelope.supports_participate()`) — return
     `unsupported_mode("participate", &state.envelope.supported_modes)`.
   - Add `"write_mode": write_mode.as_str()` to the success envelope.

4. **`whoami` envelope (`mcp/src/tools.rs::whoami`):**
   - Derive a cached `Envelope` from `Config` at process start (compute once
     in `McpState::new`):
     - `supported_modes: ["local"] | ["local", "participate"]` based on
       `storage_mode == "full"` AND a funded keypair / Arweave wiring present.
     - `default_mode: "local"`.
     - `participate_cost`: `null` if `supported_modes == ["local"]`. Else
       `{ currency: "USD", amount_cents, payment_methods }` where
       `amount_cents` is the current pricing-engine estimate (use existing
       `state.pricing.current_price().usd_cents`) and `payment_methods` is
       derived from `payment_mode`: `none → []`, `balance → ["balance"]`,
       `x402 → ["x402"]`, `both → ["x402","balance"]`.
   - `whoami` returns the existing fields PLUS `supported_modes`,
     `default_mode`, `participate_cost`. Existing `storage_mode` field is
     KEPT verbatim (legacy clients).

5. **Typed errors (new helpers in `mcp/src/mcp.rs` or a new
   `mcp/src/errors.rs`):**
   - `unsupported_mode(requested: &str, supported: &[&str]) -> JsonRpcError` →
     code `-32010`, message `"Unsupported mode"`, data
     `{ kind: "UnsupportedMode", requested, supported }`.
   - `invalid_params(field: &str, received: &serde_json::Value) ->
     JsonRpcError` → code `-32602`, message `"Invalid params"`, data
     `{ field, received }`.

6. **Golden fixture test** (`mcp/tests/modes_per_request.rs`, new file):
   - `mode_absent_response_shape_is_unchanged_from_legacy`: capture the
     `mnemonic_sign_memory` response JSON for a `mode`-absent request against
     a `STORAGE_MODE=local` test server, normalise volatile fields (timestamps,
     UUIDs, tx ids), assert byte-equality with a checked-in fixture under
     `mcp/tests/fixtures/modes/legacy_sign_response.json`. Any future shape
     drift fails this test.

7. **Integration tests in the same `mcp/tests/modes_per_request.rs`:**
   - `local_against_full_server_returns_free`: `STORAGE_MODE=full +
     PAYMENT_MODE=x402` server; `sign_memory { mode: "local" }` succeeds with
     `local:`-prefixed synthetic IDs, no Arweave/Solana writes (mock servers
     receive zero calls), no `attestation_costs` row.
   - `participate_against_local_only_server_returns_unsupported`:
     `STORAGE_MODE=local` server; `sign_memory { mode: "participate" }`
     returns `-32010` with `data.supported == ["local"]`; DB unchanged.
   - `whoami_envelope_per_deploy_variant`: three sub-cases asserting envelope
     shape for local-only, self-operator (`full + none`), hosted-x402.
   - `invalid_mode_returns_invalid_params`: table-driven over `null`,
     non-string, `""`, `" "`, `"Local"`, `"PARTICIPATE"`, `"unknown"`. Each
     returns `-32602` with `data.field == "mode"`.
   - `mixed_mode_coexistence_recall_returns_both`: seed one DB with one
     `local` row and one `participate` row for the same `owner_pubkey`; call
     `recall`; assert both surface with their stored `write_mode` tag.

8. **Update existing call sites** in `mcp/src/tools.rs`, `mcp/src/api.rs`
   (`sign_callback_handler`), and `mcp/src/mcp.rs` to thread `WriteMode`
   through `save_attestation`. No assertion changes in
   `mcp/tests/deferred_sign_flow.rs` / `sign_callback.rs` — only internal
   helper updates.

## Acceptance Criteria

- [ ] `mnemonic_sign_memory { mode: "local" }` against a `STORAGE_MODE=full +
      PAYMENT_MODE=x402` server returns free, no chain writes, row
      `write_mode='local'`.
- [ ] `mnemonic_sign_memory` with NO `mode` field produces a response identical
      to the checked-in golden fixture (byte-equality after volatile-field
      normalisation).
- [ ] `mnemonic_sign_memory { mode: "participate" }` against a
      `STORAGE_MODE=local` server returns JSON-RPC `-32010 UnsupportedMode`
      with `data.supported == ["local"]`; no row written, no charge.
- [ ] Malformed `mode` values (`null`, non-string, empty, whitespace, case
      variants, unknown) return `-32602 InvalidParams` with
      `data.field == "mode"` and `data.received` echoing the input verbatim.
- [ ] `whoami` returns `supported_modes`, `default_mode`, `participate_cost`
      with correct shape for each of: local-only, self-operator, hosted-x402.
- [ ] Mixed-mode coexistence test passes — `recall` returns both local and
      participate rows for one owner; each tagged with its stored
      `write_mode`.
- [ ] `mcp/tests/deferred_sign_flow.rs` and `mcp/tests/sign_callback.rs` pass
      with no assertion changes (only internal helper call-site updates for
      the new `WriteMode` parameter).
- [ ] Mode resolver test asserts the paywall gate decision and the persisted
      column value come from the same value (drift impossible).
- [ ] `cargo test -p mnemonic-mcp --no-fail-fast` green.
- [ ] `cargo clippy -p mnemonic-mcp --all-targets -- -D warnings` clean.

## TDD Anchor

First test (in `mcp/tests/modes_per_request.rs`):

```rust
#[tokio::test]
async fn participate_against_local_only_server_returns_unsupported_mode() {
    let server = TestServer::builder().storage_mode("local").build().await;
    let resp = server.call_tool("mnemonic_sign_memory",
        json!({ "content": "hi", "mode": "participate" })).await;
    let err = resp.error.expect("expected error");
    assert_eq!(err.code, -32010);
    let data = err.data.as_object().unwrap();
    assert_eq!(data["kind"], "UnsupportedMode");
    assert_eq!(data["requested"], "participate");
    assert_eq!(data["supported"], json!(["local"]));
    // DB must be unchanged.
    assert_eq!(server.attestation_count().await, 0);
}
```
