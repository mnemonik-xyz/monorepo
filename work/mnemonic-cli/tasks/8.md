# Task 8: Integration tests (mock server with fault injection) + cross-runtime CI matrix

## Required Skills

Before starting, load: `/skill:code-writing`

## Description

Build the integration test layer + the CI matrix. Per the test-reviewer's findings: the mock server must include explicit fault-injection toggles (5xx, malformed CBOR, expired JWT mid-flow, signer mismatch, callback timeout); the CI matrix must run on Node 20 / Node 22 / Bun / Deno (Decision 11 / Deviation 5 — Deno upgraded from manual-only).

After this task: every PR runs SDK + CLI test suites on all four runtimes; bundle-size gate enforces SDK ≤500KB / CLI ≤200KB; mock-server fault paths are exercised by at least one integration test each.

## What to do

1. **Build `packages/sdk/test/mock-server.ts`** — an in-process HTTP server. Listens on a free port via `node:net.createServer().listen(0)`. Routes:
   - `POST /mcp` (JSON-RPC dispatch) — handles `tools/list`, `tools/call` for all 5 tools. For `mnemonic_sign_memory` returns the **pending-bundle** shape (`{correlation_id, payload_cbor_base64, expires_at}`).
   - `GET /oauth/authorize` — issues an authorization code via simple state-keyed map.
   - `POST /oauth/token` — exchanges code for a fake but valid-shaped JWT (HS256-signed with a test secret).
   - `POST /oauth/register` — accepts dynamic client registration (returns `{client_id}` echo).
   - `POST /api/sign-callback` — validates COSE envelope shape (calls Rust core via WASM if available; or accepts any well-formed envelope in test mode), returns `{attestation_id}`.
   - `POST /api/cli-bootstrap/issue` and `GET /api/cli-bootstrap/redeem/:ticket` — mirror server behavior.
2. **Fault-injection** via `withFault(mode)` global setter. Modes:
   - `'5xx-on-token-exchange'` — `/oauth/token` returns 500.
   - `'malformed-cbor-in-pending'` — `tools/call name=sign_memory` returns base64 of garbage bytes.
   - `'expired-jwt-after-N-requests'` — N (configurable) requests succeed, then all subsequent return 401.
   - `'signer-pubkey-mismatch'` — `/api/sign-callback` returns 400 "signer ≠ JWT sub".
   - `'callback-timeout'` — `/oauth/token` hangs (no response within 30s).
   Reset between tests via `mockServer.reset()`.

3. **Integration tests** in `packages/sdk/test/integration/*.test.ts`:
   - `oauth-flow.test.ts` — full PKCE round-trip. Variant: with `withFault('callback-timeout')` assert `AuthError` raised within reasonable time.
   - `sign-flow.test.ts` — full sign cycle including pending-bundle decode + COSE + callback. Variant: with `withFault('malformed-cbor-in-pending')` assert SDK throws `IntegrityError` and does NOT call `/api/sign-callback`.
   - `recall-verify.test.ts` — recall → verify happy path; verify=tampered exit code 3.
   - `bootstrap-ticket.test.ts` — issue ticket, redeem, second redeem fails.

4. **Integration tests** in `packages/cli/test/integration/*.test.ts` via `execa`:
   - Spawn `mnemonic init`, `mnemonic login --token <fake>`, `mnemonic sign`, etc., against the mock server (set `MNEMONIC_BASE_URL` env). Assert exit codes and stdout.

5. **`.github/workflows/node-test.yml`** — new file:
   - Trigger: `pull_request`, `push` to `main`/`dev`.
   - Matrix: `os: [ubuntu-latest]`, `runtime: [node-20, node-22, bun-latest, deno-1.40]`.
   - Steps per matrix entry: checkout, install runtime, `bun install` (workspaces), `cd packages/sdk && bun test`, `cd packages/cli && bun test`.
   - Lockstep gate from Task 4: `cargo test --features golden-fixtures ... | sha256sum | diff - packages/sdk/test/fixtures/golden-cose.sha256`.
   - Bundle-size gate: `cd packages/sdk && npm pack --dry-run --json | jq '.[0].size'` asserted `< 500_000`. Same for CLI `< 200_000`.

6. **Smoke verification.** Open a draft PR; observe matrix runs all four runtimes green; bundle-size job reports actual sizes within budget.
