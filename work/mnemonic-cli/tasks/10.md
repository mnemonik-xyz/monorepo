# Task 10: Code Audit

## Required Skills

Before starting, load: `/skill:code-reviewing`

## Description

Holistic code-quality audit across all SDK + CLI source AND the new server-side changes from Task 6 + webapp changes from Task 7. Read every file under `packages/sdk/src/`, `packages/cli/src/`, plus `mcp/src/oauth.rs`, `mcp/src/api.rs` (changed bits), `webapp/src/components/IdentityPanel.tsx` (changed bits). Look for:

- **Maintainability**: function size, naming clarity, dead code, unclear control flow.
- **Idiomatic TypeScript**: ESM-correct imports, no `any`, no `require()`, types not blanket-`unknown`, optional chaining where appropriate, no class-instances-without-need.
- **Idiomatic Rust** (server side): error handling via `Result + ?`, no `unwrap()` outside tests, lifetimes correct, no needless clones.
- **ESM/Web-API correctness in SDK**: `grep -r 'node:' packages/sdk/src/` returns empty. `fetch` used directly (no `axios`). `crypto.subtle` not Node's `crypto`.
- **Error handling coverage**: every async path either returns a typed error or propagates; no silent catches.
- **Naming consistency**: `signer_pubkey` vs `signerPubkey` consistency between server JSON and SDK types.
- **Decision-fidelity**: spot-check that Decisions 1, 4, 7, 14, 12 are visible in the implementation (not silently violated).

After this task: a report at `work/mnemonic-cli/logs/working/audit/code-auditor.json` listing findings by severity (critical, major, minor) with concrete file:line refs.

## What to do

1. **Read all SDK source** — every file in `packages/sdk/src/`. Note any non-trivial findings.

2. **Read all CLI source** — every file in `packages/cli/src/` and `packages/cli/bin/`.

3. **Read server changes** — git diff `mcp/src/oauth.rs` and `mcp/src/api.rs` against `main` baseline. Audit the new code only.

4. **Read webapp changes** — git diff `webapp/src/components/IdentityPanel.tsx` against `main`. Audit new code.

5. **Read tests** — sample `packages/sdk/test/integration/*.test.ts` and `packages/cli/test/integration/*.test.ts` for code quality (not coverage — that's Task 12's scope).

6. **Write report** to `work/mnemonic-cli/logs/working/audit/code-auditor.json`:
   ```json
   {
     "status": "approved" | "issues_found",
     "findings": [

     ]
   }
   ```

7. **Append a decisions.md entry** summarizing the audit outcome (1-3 sentences + JSON path).
