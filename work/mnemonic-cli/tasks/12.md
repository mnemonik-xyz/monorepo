# Task 12: Test Audit

## Required Skills

Before starting, load: `/skill:test-master`

## Description

Test quality + coverage audit across SDK + CLI + new server-side test additions in Task 6. Specifically verify:

- **Golden COSE fixture lockstep gate** (Decision 12 / Task 4) — assert CI workflow includes `sha256sum | diff` step that fails on drift; manually trigger drift (modify fixture by 1 byte) and observe red CI in a draft PR.
- **Mock-server fault injection** (Task 8) — every fault mode (`5xx-on-token-exchange`, `malformed-cbor-in-pending`, `expired-jwt-after-N-requests`, `signer-pubkey-mismatch`, `callback-timeout`) is exercised by at least one integration test.
- **Bootstrap-ticket replay test** — assert second `consume()` of same ticket returns 410.
- **Redaction tests** — assert JWT and 64-byte secret hex never appear in `process.stderr` or `process.stdout` on captured error paths.
- **Exit-code coverage** — every CLI exit code (0/1/2/3/4) has at least one test that exercises it.
- **Cross-runtime CI matrix** — assert workflow includes Node 20, Node 22, Bun, Deno; manually trigger a Bun-only failure (e.g., a syntax that errors in Bun but works in Node) to confirm matrix catches it.
- **Edge cases** — expired JWT, mismatched pubkeys, offline scenarios, double-redeem of bootstrap ticket.
- **Coverage targets** — SDK ≥85% lines / ≥80% branches; CLI ≥75% lines. Run `vitest --coverage`, parse output, assert against targets.
- **`Signer` contract suite** — `runSignerContract(LocalSigner)` actually runs, all assertions pass; suite is exported in a way future signer impls can re-import (not tightly coupled to LocalSigner).
- **Decision-7 / identity-bootstrap** — at least one happy-path + one ticket-expired + one double-redeem test.

After this task: a report at `work/mnemonic-cli/logs/working/audit/test-auditor.json` listing gaps and weaknesses with file:line references.
