# Task 11: Security Audit

## Required Skills

Before starting, load: `/skill:security-auditor`

## Description

OWASP Top 10 audit across SDK + CLI + server changes (Task 6) + webapp change (Task 7). Specific high-priority concerns from earlier validator findings:

- **PKCE state-to-verifier-and-redirect-URI binding** (Decision 5) — assert state mismatch terminates flow before any HTTP I/O; assert redirect_uri mismatch at token-exchange terminates with no token issued.
- **JWT handling + redaction** (Decision 10) — assert no JWT-shape strings appear in `process.stderr`/`stdout` on error paths. `grep -r 'jwt' packages/{sdk,cli}/src/` reviewed for accidental `console.log(jwt)` etc.
- **Keypair file mode enforcement** — Unix mode 0600 verified post-write; Windows ACL via `icacls` actually restricts (test on a Windows runner if available, else read code carefully).
- **Bootstrap-ticket replay protection** (Decision 7) — `consume(ticket_id)` is atomic remove-and-return; second call returns 410. Test under concurrent load (race two redeems).
- **Redirect-URI allowlist regex coverage** — ipv4 + ipv6 + port-only + path variants. Negative: arbitrary `https://evil.com`, `http://0.0.0.0:1234`, `http://localhost:1234` (note: `localhost` resolves to 127.0.0.1 but the regex looks for `127.0.0.1` literal — confirm intent).
- **CLI loopback HTTP server hardening** — binds 127.0.0.1 only (NOT 0.0.0.0); single-shot (terminates after one callback or timeout); state validated before any code processing.
- **Supply-chain integrity** — npm provenance attestation enabled at publish (Task 14 enforces). Confirm `--provenance` flag in publish workflow.
- **No `--to-clipboard` flag** anywhere in `packages/cli/src/commands/identity.ts`. Negative test.
- **No `node:*` imports in SDK source** — confirms SDK runtime-agnostic (security concern: a stray `node:fs` would break browser builds and could expose filesystem operations in unexpected contexts).
- **OWASP A01 (broken access control)** — bootstrap ticket with no auth on redeem is intentional capability auth, but the issue endpoint requires Bearer JWT bound to `sub`. Verify the issued ticket cannot be redeemed by a different `sub` (it can — by design; document this is OK because the ticket UUID itself is the cap).
- **OWASP A02 (cryptographic failures)** — Ed25519 always via WASM (Rust `ed25519-dalek`) not JS; `crypto.subtle.sign({name:'Ed25519'})` only as fallback when WASM unavailable.

After this task: a report at `work/mnemonic-cli/logs/working/audit/security-auditor.json` with findings by severity (critical, high, medium, low).
