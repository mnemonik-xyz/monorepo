# Task 13: Pre-deploy QA

## Required Skills

Before starting, load: `/skill:pre-deploy-qa`

## Description

Acceptance gate before deploy (Task 14). Run the full test matrix on Node 20 / Node 22 / Bun / Deno; verify every acceptance criterion in user-spec + tech-spec; run the manual smoke checklist (`packages/cli/SMOKE.md`); confirm bundle sizes within budget; confirm regression baselines hold (existing webapp e2e + existing Cursor/VS Code/Claude.ai OAuth flows still work against staging).

If any AC fails, file findings into the QA report; lead may spawn fixers (audit-wave reviewers become reviewers for the fix). If all green → handoff to Task 14.

## What to do

1. **Run automated test matrix.** From repo root:
   - `cd packages/sdk && bun test` (run on Node 20, Node 22, Bun, Deno via local switching or via CI).
   - `cd packages/cli && bun test`.
   - `cd webapp && npx vitest run` (regression).
   - `cd webapp && npx playwright test` (regression).
   - `cargo test --workspace --no-fail-fast` (regression).
   - `cargo test --features golden-fixtures -p mnemonic-core --test golden_fixtures -- --ignored emit_fixtures > /tmp/x.json && diff <(sha256sum /tmp/x.json | awk '{print $1}') <(cat packages/sdk/test/fixtures/golden-cose.sha256)` — lockstep gate.
   - `cargo clippy --workspace --all-targets -- -D warnings`.
   - `cargo fmt --all -- --check`.

2. **Verify every user-spec AC** in `work/mnemonic-cli/user-spec.md` § Критерии приёмки. For each MUST: write a one-line confirmation in the QA report (e.g., "✓ Pure ESM — `grep -r 'node:' packages/sdk/src/` returns empty").

3. **Verify every tech-spec AC** in `work/mnemonic-cli/tech-spec.md` § Acceptance Criteria. Same one-liner format.

4. **Run manual smoke** from `packages/cli/SMOKE.md`. ~10 numbered steps. Note pass/fail per step.

5. **Bundle-size check.** `cd packages/sdk && npm pack --dry-run --json | jq '.[0].size'` < 500_000. `cd packages/cli && npm pack --dry-run --json | jq '.[0].size'` < 200_000.

6. **Regression smoke against staging.** Manually: load `mnemonik.xyz/install` in browser, click "Install in Cursor" deeplink, complete OAuth, verify Cursor connector appears. Same for VS Code, Claude.ai. Confirm each flows works.

7. **Write QA report** at `work/mnemonic-cli/logs/working/qa-report.json`:
   ```json
   {
     "status": "pass" | "fail",
     "matrix": {"node-20": "pass", "node-22": "pass", "bun-latest": "pass", "deno-1.40": "pass"},
     "user_spec_acs": [{"id": "...", "status": "pass|fail", "evidence": "..."}],
     "tech_spec_acs": [...],
     "smoke_checklist": [...],
     "regressions": {"webapp_e2e": "pass", "cargo_workspace": "pass", "cursor_oauth": "pass", "vscode_oauth": "pass", "claude_oauth": "pass"},
     "bundle_sizes": {"sdk": 412345, "cli": 156789}
   }
   ```

8. **If status=pass** → append decisions.md entry, hand off to Task 14. **If status=fail** → escalate to feature-execution lead with concrete findings; do NOT proceed.
