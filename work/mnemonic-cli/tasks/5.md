# Task 5: CLI commands — all of them

## Required Skills

Before starting, load: `/skill:code-writing`

## Description

Implement the entire CLI surface in `packages/cli/`. All commands route through `bin/mnemonic.ts` (argv via `commander`); each command in `src/commands/<name>.ts`. Output formatting in `src/output.ts` (TTY-aware default, `--json`/`--quiet`/`--no-color` modes). Persistence in `src/config.ts` with file-mode 0600 enforcement on Unix and Windows ACL via `icacls`.

Per Decision 14, `whoami` and `prove` are **client-side** — they read `~/.mnemonic/{identity,token}.json` and call WASM directly; they do NOT call the existing server tools (which return the server's identity, not the user's). Per Decision 7, `identity import --ticket <uuid>` calls `GET /api/cli-bootstrap/redeem/:ticket` (no Bearer auth — capability via UUID). Per Decision 6, `login --token <jwt>` is the headless alternative to interactive OAuth.

After this task: a working `mnemonic` binary on PATH supporting init / login / sign / recall / verify / whoami / prove / identity {import, export}, with all flags from Decision 10 (`--json`, `--quiet`, `--no-color`) and exit codes (0/1/2/3/4).

## What to do

1. **`packages/cli/src/config.ts`:**
   - Resolves `~/.mnemonic/` (overridable by `MNEMONIC_CONFIG_DIR` env for testing).
   - `loadIdentity()` returns the parsed `identity.json` or throws `UserError("no identity")`.
   - `loadToken()` returns parsed `token.json` if not expired, else throws.
   - `saveIdentity(kp)` / `saveToken(jwt, exp, sub)` write with mode 0600 (`fs.chmodSync` on Unix). On Windows, after `writeFile`, call `child_process.execSync('icacls "${path}" /inheritance:r /grant:r "${process.env.USERNAME}:F"')` to restrict ACL. Wrap platform branch in `if (process.platform === 'win32')`.

2. **`packages/cli/src/output.ts`:** TTY-aware formatter.
   - `format(data, options)` — `options: {json?, quiet?, noColor?}`. Default: human-readable, color iff `process.stdout.isTTY && !noColor`. `--json`: `JSON.stringify(data, null, 2)` to stdout, all hints to stderr. `--quiet`: only `--json` (if set) emitted; nothing else.
   - Use `kleur` for color.

3. **`packages/cli/src/errors.ts`:** typed errors mirroring SDK + redaction.
   - `class UserError extends Error { exitCode = 1 }`, `ServerError {2}`, `IntegrityError {3}`, `AuthError {4}`.
   - `redactSecrets(message)` strips JWT shapes, 64-byte hex keys.
   - `handleError(err)` (used in `bin/mnemonic.ts`'s top-level try/catch): if known typed error, prints redacted message to stderr, exits with the carried code; if unknown, prints "Internal error" + redacted stack (also stderr), exits 1.

4. **`packages/cli/src/commands/init.ts`:** `mnemonic init [--force]`. Refuse if `~/.mnemonic/identity.json` exists without `--force`. Otherwise call `Keypair.generate()` from SDK, save via `saveIdentity`. Print pubkey + DID. If user has used webapp before (heuristic: nothing trivial — just print a hint), suggest `mnemonic identity import --ticket`.

5. **`packages/cli/src/commands/login.ts`:** Two paths:
   - Interactive (default): generate PKCE state via SDK's `oauth.generatePkceVerifier` etc., call `oauth.buildAuthorizeUrl({...})`, bind a one-shot HTTP server on `127.0.0.1:0` via `node:http`, open browser via `open` package, await callback. On callback receive: validate `state`, call `oauth.exchangeCodeForToken({...})`, save token via `saveToken`. Server times out after 5min and binds 127.0.0.1 ONLY (never `0.0.0.0`). Server shuts down after one callback.
   - Headless (`--token <jwt>`): parse JWT via `oauth.parseJwtPayload`, validate `alg=HS256` (decode header b64), assert `exp > now`, save via `saveToken`. No browser, no server.

6. **`packages/cli/src/commands/sign.ts`:** Reads identity + token, instantiates `MnemonicClient({baseUrl: process.env.MNEMONIC_BASE_URL || 'https://mc.mnemonik.xyz', signer: new LocalSigner(kp), jwt: tok.jwt})`, calls `client.signMemory(content, {tags})`, formats result via `output.format`. Tags from `--tags=a,b` flag. Content from positional arg or stdin if missing.

7. **`packages/cli/src/commands/recall.ts`:** `client.recall(query, {topK, tag})`. `--top-k=N` (default 5). `--tag=foo` filter.

8. **`packages/cli/src/commands/verify.ts`:** `client.verify(attestationId)`. Map result status to exit code: `verified` → 0, `tampered` → 3, `not_found` → 1.

9. **`packages/cli/src/commands/whoami.ts`:** **Client-side** per Decision 14. Read identity.json + token.json. Compute pubkey, DID, `signer_match` (do identity.pubkey and JWT sub agree?), JWT issued/expiry. Optionally call `client.recall(' ', {topK: 0})` to get total attestation count for the user. Format & print.

10. **`packages/cli/src/commands/prove.ts`:** **Client-side** per Decision 14. Read identity. Generate or accept `--challenge=<hex>` (default: 32 random bytes). Call `LocalSigner(kp).sign(challenge_bytes)` (which internally calls WASM `sign_challenge`). Output `{pubkey, challenge, signature, did}`.

11. **`packages/cli/src/commands/identity.ts`:** Subcommands `import` and `export`.
    - `import --ticket <uuid>`: `fetch('https://mc.mnemonik.xyz/api/cli-bootstrap/redeem/:ticket')`, parse JSON `{secret, pubkey_base58}`, save via `saveIdentity`. Refuse if existing identity differs unless `--force`.
    - `import --file <path>`: read file, parse, validate shape, save.
    - `export --file <path>`: write current identity.json to path with mode 0600. **No `--to-clipboard` flag.**

12. **`packages/cli/bin/mnemonic.ts`:** argv routing via `commander`. Top-level flags: `--json`, `--quiet`, `--no-color`, `--help`, `--version`. Each command registered with its options. Top-level try/catch calls `handleError`.

13. **Unit tests** in `packages/cli/test/{init,login,sign,recall,verify,whoami,prove,identity,output}.test.ts`. Use `vitest` + `execa` against the binary. Mock the network via `MSW` (mock service worker) or by injecting a custom `fetch`.
