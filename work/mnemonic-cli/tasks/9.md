# Task 9: Documentation — SDK README, CLI README, JSDoc, repo-root pointer, SMOKE.md

## Required Skills

Before starting, load: `/skill:documentation-writing`

## Description

Write the public-facing documentation. SDK README has a 5-line quick-start, the public API reference (auto-generated where possible), the runtime-target table from Task 1's investigation, and a link to the backlog. CLI README has command reference (init / login / sign / recall / verify / whoami / prove / identity), examples, exit-code table, link to SMOKE.md. Repo-root README gets one paragraph + links pointing at both packages. JSDoc on every public SDK method renders to consumable `.d.ts`.

After this task: a developer landing on the npm package page or GitHub README can install + use the CLI in under a minute, or `import { MnemonicClient } from '@mnemonik-xyz/sdk'` and start coding without spelunking the source.

## What to do

1. **`packages/sdk/README.md`:**
   - One-paragraph what & why.
   - **Quick start** (5 lines):
     ```typescript
     import { MnemonicClient, LocalSigner, Keypair } from '@mnemonik-xyz/sdk';
     const kp = Keypair.fromJSON(JSON.parse(localStorage.getItem('mnemonic.identity')!));
     const client = new MnemonicClient({ baseUrl: 'https://mc.mnemonik.xyz', signer: new LocalSigner(kp), jwt });
     const { attestationId } = await client.signMemory('hello', { tags: ['demo'] });
     ```
   - **Runtime targets** table (filled from Task 1's investigation): which wasm-pack target, which runtimes confirmed, conditional exports if any.
   - **API reference** — list of public exports with one-line descriptions: `MnemonicClient`, `Signer`, `LocalSigner`, `Keypair`, `buildAuthorizeUrl`, `exchangeCodeForToken`. Link to JSDoc / typedoc-rendered HTML if generated.
   - **Backlog & roadmap** — link to `work/mnemonic-cli/backlog.md`.
   - **License** — match repo (MIT or whatever).

2. **`packages/cli/README.md`:**
   - One-paragraph what & why.
   - **Install:** `npm install -g @mnemonik-xyz/cli` (also Bun, Deno).
   - **Quick start:** `mnemonic init && mnemonic login && mnemonic sign "hello"`.
   - **Commands** — for each: synopsis, options, example invocation, expected output (truncated). Cover all of init / login (interactive + `--token`) / sign / recall / verify / whoami / prove / identity {import, export}.
   - **Output flags:** `--json`, `--quiet`, `--no-color`, with one-line examples.
   - **Exit codes** table: 0 / 1 / 2 / 3 / 4 with descriptions.
   - **Manual smoke checklist** — link to `packages/cli/SMOKE.md`.
   - **License**.

3. **`packages/cli/SMOKE.md`** — manual pre-release smoke checklist. Adapt from § "Manual smoke tests" in tech-spec. ~10 numbered steps, each with expected outcome (file exists, mode is 0600, exit code 0, etc.).

4. **JSDoc on public SDK methods.** Every exported function/class/interface in `packages/sdk/src/{client,signer,keypair,oauth,types}.ts` gets a JSDoc block: one-line summary, `@param` for each arg, `@returns`, `@throws` for documented error types, `@example` block with a runnable snippet. Run `npx typedoc packages/sdk/src/index.ts --emit none` and assert no missing-doc warnings.

5. **Repo-root `README.md`** — add a "Programmatic access" section pointing at:
   - `@mnemonik-xyz/cli` for terminal use.
   - `@mnemonik-xyz/sdk` for programmatic JS/TS integration.
   - Brief blurb that both reuse the same OAuth + COSE substrate as Cursor/VS Code/Claude.ai.

6. **Smoke verification.** `npx typedoc packages/sdk/src/index.ts --emit none` clean. Visually review rendered Markdown via `gh markdown` or local preview.
