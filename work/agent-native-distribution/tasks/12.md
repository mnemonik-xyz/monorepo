# Task 12: Pre-deploy QA

## Required Skills

- `/skill:pre-deploy-qa` — [skills/pre-deploy-qa/SKILL.md](~/.claude/skills/pre-deploy-qa/SKILL.md)

## Description

Final acceptance testing before deploy. Run the entire test suite (`cargo test --workspace`, `cargo clippy --workspace -- -D warnings`, `cargo fmt --all -- --check`, `npx vitest run` in `packages/mcp/` and `packages/cli/`). Verify each user-spec AC (AC1-AC17) and each tech-spec acceptance criterion against a freshly-built local binary + freshly-installed shim in a tempdir HOME. Walk through each row of the user-spec "Как проверить" agent-checks table and confirm passes against the locally-running binary.

## What to do

- Tool / lint gates:
  - `cargo test --workspace --no-fail-fast` → all pass (or known-skipped) — capture output to `work/agent-native-distribution/logs/working/task-12/cargo-test.txt`
  - `cargo clippy --workspace --all-targets -- -D warnings` → clean
  - `cargo fmt --all -- --check` → clean
  - `cd packages/mcp && npx vitest run` → all pass
  - `cd packages/cli && npx vitest run` → all pass (no regression from Task 6)
  - `cd packages/sdk && npm test` → all pass (no regression)
- Build the production binary: `cargo build --release -p mnemonic-mcp --features local-embed`
- Build the shim package: `cd packages/mcp && npm install && npm run build`
- In a tempdir HOME (no real `~/.mnemonic/`), walk through every row of user-spec "Как проверить" table:
  - Row 1 anonymous discovery 7 prompts — exec curl, capture, assert.
  - Row 2 anonymous discovery 7 resources — same.
  - Row 3 tools/list enriched descriptions — same; each tool description ≥ documented length.
  - Row 4 anonymous recall returns only public — seed DB via direct SQL, query via curl, assert filter holds.
  - Row 5 install idempotent — pre-populate `~/.claude.json` with unrelated entry, run install, dump, run install, dump, diff, assert byte-identical.
  - Row 6 install --check is dry-run — capture mtime before/after, assert unchanged.
  - Row 7 local sign offline — `unshare -rn` (Linux) or "airplane mode + assert via `sudo nettop`" (macOS, manual).
  - Row 8 default no silent escalation — embedder cache removed, call sign_memory without `allow_fallback_to_participate=true`, assert typed error + zero outbound.
  - Row 9 explicit opt-in fallback — same with `allow_fallback_to_participate=true`, assert success + `escalated` field.
  - Row 10 visibility rejected on local — assert -32602.
  - Row 11 token cached after login — assert file appears at `~/.mnemonic/token.json` (NOT keychain per Decision 7), file mode 0o600.
  - Row 12 embedder config surface — `initialize` response has `embedder.model_id`, `embedder.model_version`, `embedder.dim`.
  - Row 13 doctor diagnoses keychain corruption (or token file corruption) — corrupt fixture file, run doctor, assert exit 1 + repair hint.
  - Row 14 deferred per Decision 7 (no token migration in v1) — skip with note.
- Verify each AC from tech-spec Acceptance Criteria section against the actual codebase.
- Verify ACs from user-spec Critical Acceptance section (AC1-AC17 — note AC12 reframed per Decision 7).
- Produce a structured pass/fail report at `work/agent-native-distribution/logs/working/task-12/qa-report.json` with fields: `{ ac_results: [{id, status, notes}], tool_gates: {lint, format, tests}, smoke_results: [{row, status, output_excerpt}] }`.
