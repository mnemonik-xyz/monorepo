# Task 7: @mnemonik-xyz/mcp shim — full package (bin + lazy-install + hardened download/verify + all subcommands)

## Required Skills

- `/skill:code-writing` — [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Single owner of all `packages/mcp/` content in Wave 4 (per tech-spec wave-conflict resolution). Create the npm shim package `@mnemonik-xyz/mcp` that ships `bin/mnemonik-mcp` (note bin name spelling: `mnemonik-mcp` with `k`, matching npm scope). Bin entrypoint dispatches between `install`, `install --check`, `mcp-stdio`, `doctor` subcommands. No `postinstall` script (security hardening per Decision 8) — first invocation lazy-runs `install-binary`. The lazy installer downloads the matching platform tarball from GitHub Releases, verifies SHA256 against the release's `SHA256SUMS` manifest, additionally verifies via `gh attestation verify` pinned to `--owner mnemonik-xyz --repo mnemonik-xyz/monorepo --signer-workflow .github/workflows/release.yml`, extracts using zip-slip-hardened tar (version pinned for CVE-2021-32803/04), caches under `~/.local/share/@mnemonik-xyz/mcp/bin/mnemonik-mcp`, writes a `manifest.json` sidecar with the SHA256 line + attestation bundle + publisher identity tuple for doctor's later re-verification. `install` subcommand follows Decision 9: hardcoded 3 macOS host candidates, lstat-symlink-out-of-home check, atomic tempfile + rename, non-destructive JSON merge, idempotent, output ends with restart-instruction string. `--confirm` flag for interactive TTY prompt. `install --check` is dry-run (mtime-unchanged verified). `doctor` runs 6 checks (host-config entry presence, /health ping, binary integrity via `manifest.json` not re-download, local SQLite r/w, identity accessibility, token file integrity).

## What to do

- Create `packages/mcp/` directory with `package.json`:
  - `name: "@mnemonik-xyz/mcp"`, `version` matching the workspace (start at `0.2.0` or current cli version).
  - `bin: { "mnemonik-mcp": "./dist/bin/mnemonik-mcp.js" }`.
  - `type: "module"`, `engines.node >= 20` (Node 20 LTS minimum; Node 22+ recommended). Built-in `fetch` is stable since Node 18.
  - `scripts.build`: `tsc -b`. `scripts.test`: `vitest run`.
  - `dependencies`: `tar` (pinned to a version known to mitigate CVE-2021-32803/04, e.g., `^7.4.0`).
  - `devDependencies`: `typescript`, `vitest`, `tsx`, `@types/node`, `@types/tar`.
- `packages/mcp/tsconfig.json` — extends `packages/cli/tsconfig.json` if shape compatible, else mirror.
- `packages/mcp/dist/binary-version.json` (committed): `{ "tag": "v0.2.0", "artifacts": { "darwin-arm64": "mnemonic-mcp-v0.2.0-aarch64-apple-darwin.tar.gz", "darwin-x64": "mnemonic-mcp-v0.2.0-x86_64-apple-darwin.tar.gz" } }`. Linux/Windows omitted for v1 per user-spec scope.
- `packages/mcp/src/bin/mnemonik-mcp.ts` — entrypoint. Argv parsing (use minimal parsing — no commander dep for the shim; switch on `process.argv[2]`). Dispatch:
  - `install` → run `installHosts({ check: false, confirm: argv.includes('--confirm') })`.
  - `install --check` → run `installHosts({ check: true })`.
  - `mcp-stdio` → run `mcpStdio()` (spawn the cached binary as subprocess, forward stdio).
  - `doctor` → run `doctor()`.
  - Any other / no subcommand → print usage and exit 1.
  - Before any subcommand executes (except usage), call `ensureBinaryCached()` from `install-binary.ts` which lazy-installs if cache is empty.
- `packages/mcp/src/install-binary.ts`:
  - `export async function ensureBinaryCached(): Promise<string>` — returns the absolute path to the cached binary; downloads/verifies/extracts if cache is empty.
  - Steps: (1) read `dist/binary-version.json` for tag + per-platform artifact name. (2) Compute cache path `~/.local/share/@mnemonik-xyz/mcp/bin/mnemonik-mcp` (or `process.env.XDG_DATA_HOME` equivalent). If exists AND `manifest.json` sidecar verifies via SHA + attestation, return path immediately. (3) Otherwise download `https://github.com/mnemonik-xyz/monorepo/releases/download/${tag}/${artifact}` and `https://github.com/mnemonik-xyz/monorepo/releases/download/${tag}/SHA256SUMS`. (4) Verify SHA256 of artifact against the `SHA256SUMS` line for that exact filename. Mismatch → throw with clear error. (5) Run `gh attestation verify <tarball> --owner mnemonik-xyz --repo mnemonik-xyz/monorepo --signer-workflow .github/workflows/release.yml` via `child_process.spawn`. Non-zero exit → throw. (6) Extract via `tar.extract` with `filter: (entryPath, entry) => { const resolved = path.resolve(cacheDir, entryPath); const rel = path.relative(cacheDir, resolved); const isInside = rel !== '' && !rel.startsWith('..') && !path.isAbsolute(rel); return isInside && entry.type !== 'SymbolicLink' && entry.type !== 'Link'; }` (zip-slip hardening: resolves the entry path against cacheDir, asserts the resolved path stays within cacheDir; also rejects hard-link entries which can escape via different mechanisms). (7) chmod cached binary to `0o755`; cache directory to `0o700`. (8) Write `manifest.json` sidecar: `{ sha256: "...", sha256sums_url: "...", attestation_subject: "...", publisher: { owner, repo, workflow } }`.
- `packages/mcp/src/install-hosts.ts`:
  - `export async function installHosts({ check, confirm }: { check?: boolean; confirm?: boolean })`.
  - Candidates (hardcoded, only-if-exists): `~/.claude.json`, `~/Library/Application Support/Claude/claude_desktop_config.json`, `~/.cursor/mcp.json`.
  - For each present candidate: (a) `fs.lstat` to check it's not a symlink whose target escapes `os.homedir()`. If escape: throw with clear error. (b) Read + parse JSON. (c) If `check` mode: print plan line `would set mcpServers.mnemonik in <path>` and skip write. (d) Else: deep-clone, set `parsed.mcpServers ??= {}`, set `parsed.mcpServers.mnemonik = { command: "<absolute path to cached mnemonik-mcp>", args: ["mcp-stdio"] }`. (e) Write to `<candidate>.mnemonik.tmp` in same directory, fsync, rename over original.
  - If `confirm` mode: between read and write, print `would write to <path>; continue? [y/N] `; wait for stdin. Only continue on `y`/`Y`.
  - If no candidates present: print `no host configs found; install mnemonik by adding mcp.mnemonik.xyz to your agent's MCP config directly` and exit 0.
  - Final stdout line (after all writes): `If any of these agents is already running, please restart them.` (exact string per AC9 test).
- `packages/mcp/src/doctor.ts`:
  - 6 checks. For each, print `<check_name>: <pass|fail>; <details/repair_hint>`. Exit 0 if all pass, exit 1 if any fail.
  - Checks: (1) `host-config-entry-presence` — for each of 3 host candidates, if file exists, check `mcpServers.mnemonik` is set; report `n_of_3 hosts configured`. (2) `mcp-mnemonik-xyz-health` — fetch `https://mcp.mnemonik.xyz/health`, assert 200 with `{"status":"ok"}`. (3) `binary-integrity` — read `manifest.json` sidecar, recompute SHA256 of cached binary, assert match. (Do NOT re-download SHA256SUMS — that's the circular check Round 1 audit forbade.) (4) `local-sqlite-rw` — open `~/.mnemonic/attestations.db` (or create if absent), write + read + delete a test row, assert success. (5) `identity-accessible` — call `ensureBinaryCached()` then spawn `mnemonik-mcp whoami`-equivalent (or read `~/.mnemonic/identity.json` directly), assert pubkey present. (6) `token-file-integrity` — check `~/.mnemonic/token.json` is either absent (OK, will OAuth on first call) OR parses as valid JSON with `expires_at` field. Report `expired` as a soft warning. Malformed → hard fail with repair hint "delete the file and re-OAuth".
- `packages/mcp/src/mcp-stdio.ts`:
  - `export async function mcpStdio(): Promise<void>` — call `ensureBinaryCached()` to get the binary path, then `child_process.spawn(binaryPath, ['mcp-stdio'], { stdio: ['inherit', 'inherit', 'inherit'] })`. Forward exit code.

**Edge cases:**
- `gh` CLI not installed on user's machine → fail with `gh CLI is required for signature verification — install from https://cli.github.com or pin a verified binary via /home/<user>/.local/share/@mnemonik-xyz/mcp/bin/`. Do NOT fail open.
- `~/.claude.json` exists but is empty (zero-byte) — parse as `{}`, set mcpServers, write back.
- `~/.claude.json` has invalid JSON — abort with error naming the file; do NOT silently overwrite; do NOT touch the other candidates either (atomic per-file = atomic per-candidate, not all-or-nothing across candidates).
- `~/Library/Application Support/Claude/...` directory missing → only-if-file-exists guard skips it silently.
- Cache directory exists but contains a different binary (e.g., older tag) → re-verify against manifest.json; if mismatch, redownload.
- `node` running with `--ignore-scripts` — fine because there's no postinstall script (Decision 8). All install happens lazily on first invocation.

**Implementation hints:**
- Use Node 22's built-in `fetch` — no `undici` dep needed.
- `tar` v7 (pinned): `import * as tar from 'tar'; await tar.extract({ file, cwd: cacheDir, filter: (path, entry) => { /* zip-slip + symlink skip */ } });`
- For SHA256: `import { createHash } from 'node:crypto'; const hash = createHash('sha256'); hash.update(buffer); hash.digest('hex');`
- For atomic write of JSON: `await fs.writeFile(tmpPath, JSON.stringify(content, null, 2)); await fs.rename(tmpPath, finalPath);` — both ops in same directory for rename atomicity.
- For symlink-out-of-home check: `const stat = await fs.lstat(candidate); if (stat.isSymbolicLink()) { const target = await fs.realpath(candidate); if (!target.startsWith(os.homedir() + path.sep)) throw ...; }`.
- For doctor's mock-friendly /health check: `const res = await fetch('https://mcp.mnemonik.xyz/health'); assert(res.status === 200); const body = await res.json(); assert(body.status === 'ok');` — vitest mocks fetch via `vi.stubGlobal`.
- For doctor's parametrized failure tests: use vitest's `test.each` over a fixture array; each row is `{ name, setup: () => void, expectedFailingCheck: string }`.
