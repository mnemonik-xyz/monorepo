## Description

Wire the typed resolvers for `visibility` and `allow_fallback_to_participate` into `sign_memory`, with `mode=local + visibility=...` rejected via `invalid_params`. **Edge cases:**
- `sign_memory { mode: "participate", visibility: "public", public_write_confirmation: "<garbage>" }` → reconstructed HMAC doesn't match → `-32095`.
- `sign_memory { mode: "participate" }` (visibility absent → default Private) → no confirmation gate; flow proceeds normally.
- Server restart between mint and consume → token lost (DashMap is in-process, intentional per Decision 5b). Client retries the full ceremony — surface this in `mnemonik-attest.md` skill manifest (Task 1).
- HMAC secret must be regenerated on each `McpState::build()` call, not persisted. (Process-scoped per Decision 5b.) Verify with unit test.
- `request_public_write_confirmation` with `content_hash` longer than expected length — just include in HMAC as-is; no length validation.

**Implementation hints:**
- Use `hmac::Mac` trait: `let mut mac = HmacSha256::new_from_slice(&secret)?; mac.update(content_hash.as_bytes()); mac.update(owner_pubkey.as_bytes()); mac.update(visibility.to_string().as_bytes()); mac.update(&expires_at.to_be_bytes()); mac.update(jti.as_bytes()); let result = mac.finalize().into_bytes();` — emit base64url.
- `DashMap::remove_if(key, predicate)` — atomic CAS. The predicate gets a reference to the value; return true to remove. Use that for both single-use enforcement and the "matches the request" check in one shot.
- Background eviction: spawn at McpState construction time, `tokio::spawn(async move { loop { tokio::time::sleep(EVICT_TICK).await; ledger.evict_expired(); } })`. Hold the join handle for graceful shutdown.
- For the parametrized Error Catalogue test, define `enum TriggerKind { HeldSqliteLock, BrokenEmbedder, DeniedKeychain, HungOauthMock, UnreachableHosted, ExpiredClock, ConfirmationGateViolation, MalformedArgs }`. Map each row in the catalogue to a TriggerKind + trigger closure. Each closure sets up the precondition and returns the JSON-RPC request to send.
