# Task 5: mcp-stdio + logout subcommands on Rust binary + MNEMONIC_HOSTED_ENDPOINT gating + soft-fall routing

## Required Skills

- `/skill:code-writing` — [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Single owner of all `mcp/src/main.rs` + `mcp/src/tools.rs` (soft-fall routing) + `mcp/src/mcp.rs` (route hookup) edits in Wave 3. Adds three clap subcommands to `mnemonic-mcp`: `mcp-stdio` (alias for the existing `--transport stdio` flow, used by hosts), `logout` (file unlink of `~/.mnemonic/token.json`), and `--allow-custom-endpoint` flag on the top-level CLI. Wires the soft-fall routing for `sign_memory` per Decision 4: when `allow_fallback_to_participate=true` and local execution fails, re-dispatch through participate HTTPS proxy; on success, response carries `escalated: {from, to, reason}`; on hosted unavailability, error is `-32011 HostedUnavailable` (not the original local-failure code). Visibility re-resolution after escalation per Decision 4 ensures `public_write_confirmation` is still enforced.

## What to do

- In `mcp/src/main.rs` clap parser: add subcommand `Mcp-stdio` (no args; reuses the existing `run_stdio()` path at `main.rs:576-617`). Existing `mnemonic-mcp` invocation without subcommand still works (`--transport stdio` flow unchanged).
- Add subcommand `Logout` (no args). Implementation: read `~/.mnemonic/token.json` path via the same helper as Task 6's `token_store` (use `core::identity::token_store::token_path()`). If file exists, `unlink()` it. If not, exit 0 silently. Print `mnemonic: logged out` to stderr.
- Add top-level CLI flag `--allow-custom-endpoint: bool` (default false). When false, `MNEMONIC_HOSTED_ENDPOINT` env var is ignored AND a single-line stderr warning is emitted if the env var is set (warning text: `[mnemonik-mcp] ignoring MNEMONIC_HOSTED_ENDPOINT — use --allow-custom-endpoint to enable`). When true, the env var is read and used. Default hosted endpoint is the compile-time baked constant `https://mcp.mnemonik.xyz/mcp`.
- In `mcp/src/tools.rs`, in the `sign_memory` body, after the existing local-mode execution path returns an error AND `allow_fallback_to_participate == true`: re-dispatch the SAME `SignArgs` (with `mode` swapped to `Participate` and the original `visibility` preserved). The participate path proxies via HTTPS to the resolved hosted endpoint. Per Decision 4, the new participate dispatch runs the visibility resolver AGAIN — so `public_write_confirmation` enforcement from Task 4 still applies (if missing on a `visibility=public` escalation, `-32095` is returned and the escalation is undone — no chain write).
- Build the response: on successful escalation, the JSON-RPC `result` includes a new field `escalated: { from: "local", to: "participate", reason: <enum-as-string> }`. Reason values: `"embedder_unavailable"`, `"local_storage_busy"`, `"identity_bootstrap_failed"`. Stderr line: `[mnemonik] participate-mode write: <pubkey_truncated> <content_hash> visibility=<v>` per user-spec Flow 3.
- On hosted unavailability during escalation: return `-32011 HostedUnavailable { kind, last_error, retry_after_ms: 500 }` (NOT the original local-failure code) — agent sees the actual failure point per Decision 4.
- Route hookup in `mcp/src/mcp.rs`: ensure the new `request_public_write_confirmation` dispatcher arm (added by Task 4) is reachable from the stdio subcommand path (it should be, since `mcp-stdio` reuses the same `handle_request` dispatcher).

**Implementation hints:**
- Clap pattern: `#[derive(Parser)] struct Cli { #[command(subcommand)] command: Option<Command>, #[arg(long, global = true)] allow_custom_endpoint: bool, /* existing args */ }` + `#[derive(Subcommand)] enum Command { McpStdio, Logout }`.
- For env var resolution: after clap parsing, if `args.allow_custom_endpoint && std::env::var("MNEMONIC_HOSTED_ENDPOINT").is_ok()`, use the env value. Else if env is set but flag is not, `eprintln!()` the warning once and use `DEFAULT_HOSTED_ENDPOINT`. Pass the resolved endpoint into `McpState::build()`.
- For test-only `McpState` constructor: add `pub fn with_embedder_for_test(embedder: Box<dyn Embedder>, ...)` under `#[cfg(test)]` so tests can inject `FailingEmbedder`.
- `FailingEmbedder` test impl in `core/tests/support/failing_embedder.rs`: implements `Embedder` trait, increments a counter on each `embed()` call, returns `Err(...)` when counter reaches `fail_on_call`.
- For `unshare -rn` test: gate behind `#[cfg(target_os = "linux")]` since macOS doesn't support netns. Use `nix::sched::unshare(CloneFlags::CLONE_NEWNET)`. The test runs as a child process to inherit the new netns.
