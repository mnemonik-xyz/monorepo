# Task 8: release.yml SHA256SUMS + GitHub artifact attestation + @mnemonik-xyz/mcp publish

## Required Skills

- `/skill:deploy-pipeline` — [skills/deploy-pipeline/SKILL.md](~/.claude/skills/deploy-pipeline/SKILL.md)

## Description

Extend `.github/workflows/release.yml` with three additions: (1) generate `SHA256SUMS` from all built `mnemonic-mcp-*.tar.gz` artifacts after `build-linux` + `build-macos` complete, attach to the GitHub Release; (2) emit GitHub artifact attestations via `actions/attest-build-provenance@v1` over the same artifacts (the shim's `install-binary.ts` from Task 7 will verify these via `gh attestation verify`); (3) add a new `publish-mcp-shim` job mirroring the existing `publish-npm` job — Trusted Publishing via OIDC (no NPM_TOKEN), `npm publish --access public --provenance` on `packages/mcp/`, with the same skip-if-already-published guard.

## What to do

- In `.github/workflows/release.yml`, in the `release` job at lines 110-125 (the one with `needs: [build-linux, build-macos]`):
  - After `actions/download-artifact@v4` collects all tarballs into `artifacts/`, add a step `Generate SHA256SUMS`:
    ```
    - name: Generate SHA256SUMS
      run: |
        cd artifacts
        find . -name 'mnemonic-mcp-*.tar.gz' -exec sha256sum -b {} \; > SHA256SUMS
        # Normalize relative paths
        sed -i 's| \*\./| \*|' SHA256SUMS
        cat SHA256SUMS
    ```
  - Add `actions/attest-build-provenance@v1` step BEFORE the release-create step:
    ```
    - name: Attest build provenance
      uses: actions/attest-build-provenance@v1
      with:
        subject-path: 'artifacts/**/mnemonic-mcp-*.tar.gz'
    ```
  - Update the `softprops/action-gh-release@v2` step to also include `SHA256SUMS`:
    ```
    files: |
      artifacts/**/*.tar.gz
      artifacts/SHA256SUMS
    ```
  - Add `id-token: write` and `attestations: write` to the `release` job's `permissions:` block (required by attest-build-provenance).
- Add a new job `publish-mcp-shim` analogous to the existing `publish-npm` job (around `release.yml:132-216`):
  - `needs: [release]` so it runs after SHA256SUMS + attestation are published.
  - `runs-on: ubuntu-latest`.
  - `permissions: id-token: write, contents: read` (Trusted Publishing requirement).
  - Steps mirror `publish-npm`: checkout, setup-node, install deps, build, publish.
  - Build step: `npm install -g npm@latest` (already done by existing job) + `cd packages/mcp && npm install && npm run build`.
  - Publish step: same skip-if-already-published guard pattern:
    ```
    LOCAL=$(node -p "require('./packages/mcp/package.json').version")
    REMOTE=$(npm view @mnemonik-xyz/mcp version 2>/dev/null || echo "")
    if [ "$LOCAL" = "$REMOTE" ]; then echo "@mnemonik-xyz/mcp $LOCAL already on registry — skipping"; else npm publish --access public --provenance --workspace packages/mcp; fi
    ```
- Verify the existing `publish-npm` job at lines 132-216 is untouched (it publishes sdk + cli, unrelated to the shim).
