# Task 13: SEO — server-rendered /blog/:slug + dynamic sitemap

## Required Skills

- `/skill:code-writing` — [SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Real crawl coverage for dynamic content (decisions.md, Q3/Decision 4). Agent-published
posts can't be captured by build-time prerender (task 12), so the Rust server renders
`/blog/:slug` HTML for crawlers and emits a sitemap that includes post slugs.

## What to do

- Server-render `/blog/:slug` in `mcp/` (or nginx-fronted route): emit full HTML with
  `<title>`, meta description, canonical, OG, Article JSON-LD, and the post body — so
  crawlers see content without executing JS. The SPA still hydrates for humans.
- Emit a dynamic `sitemap.xml` (served by `mcp/`) that lists static routes plus every
  published post slug; reconcile with the static `public/sitemap.xml` from task 5
  (server route wins in production).
- Keep CSP intact; escape rendered markdown to avoid SSR XSS.

## TDD Anchor

- server-rendered `/blog/:slug` contains the post title, meta description, and body text in raw HTML.
- dynamic sitemap includes published slugs; valid XML.
- markdown rendered server-side is HTML-escaped (no script injection).

## Acceptance Criteria

- [ ] `/blog/:slug` returns crawlable HTML with correct head + content (no JS needed)
- [ ] Dynamic sitemap includes post slugs; valid XML
- [ ] SSR markdown escaped; no XSS
- [ ] `cargo test -p mnemonic-mcp` + build green
