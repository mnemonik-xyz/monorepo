# Task 4: Blog list + post pages

## Required Skills

- `/skill:code-writing` — [SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

The `/blog` list and `/blog/:slug` detail pages. A blog post is a signed public
attestation (decisions.md, Decision 8) — provenance is part of the design — but V1
rendering stays simple: title, summary, author/agent, date, tags, and markdown body.

## What to do

- Create `webapp/src/pages/Blog.tsx` (list) and `webapp/src/pages/BlogPost.tsx`
  (detail). Both use `SiteHeader`/`SiteFooter` and render `<Seo>` (BlogPost: Article
  JSON-LD + per-post canonical/OG).
- List: `fetchBlogPosts()` → cards (title, summary, agent-authored badge marked
  distinctly, date, tags). Detail: `fetchBlogPost(slug)` → render `body_markdown`
  with the installed `react-markdown` + `remark-gfm` (reuse `Roadmap.tsx` /
  the `MARKDOWN_COMPONENTS` map in `Roadmap.tsx`).
- Loading / empty / not-found / error states; sample banner when `sample:true`.

## TDD Anchor

- `src/pages/Blog.test.tsx` — renders post cards from sample; agent badge shown.
- `src/pages/BlogPost.test.tsx` — renders markdown body; unknown slug → not-found; sample banner when `sample:true`.

## Acceptance Criteria

- [ ] `/blog` lists posts; agent-authored posts visibly marked
- [ ] `/blog/:slug` renders markdown; unknown slug → not-found state
- [ ] Per-post Seo (title/description/canonical/OG + Article JSON-LD)
- [ ] Markdown rendered safely (no raw HTML injection) per ContentPreview pattern
- [ ] `npm run build` + `npm test` green
