# Task 1: Finish frontend data + SEO libs

## Required Skills

- `/skill:code-writing` — [SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Complete the Wave-1 frontend foundation. Design tokens (`index.css`,
`tailwind.config.js`) and explorer helpers (`lib/links.ts`) are already done, and
`lib/ledger.ts` already wires `fetchArtifacts` / `fetchAttestationTimeline` with a
graceful sample-fallback — but the sample generators, the blog client, and the
`<Seo>` component are missing. Pages (tasks 2–4) depend on these.

## What to do

- Append `sampleArtifacts()` and `sampleTimeline(range)` to `webapp/src/lib/ledger.ts`.
- Create `webapp/src/lib/blog.ts`: `BlogPost` type + `fetchBlogPosts()` /
  `fetchBlogPost(slug)` with the same timeout + graceful `sample:true` fallback as `ledger.ts`.
- Create `webapp/src/lib/seo.tsx`: `<Seo>` using React 19 head hoisting (title, meta
  description, canonical, OG/Twitter, inline JSON-LD Organization/Article).

## TDD Anchor

- `src/lib/blog.test.ts` — `fetchBlogPosts` returns `sample:true` when fetch fails.
- `src/lib/ledger.test.ts` — `sampleTimeline` returns correct bucket count + totals per range.
- `src/lib/seo.test.tsx` — `<Seo>` renders title, meta description, canonical, JSON-LD script.

## Acceptance Criteria

- [ ] `sampleArtifacts()` returns mixed write_mode rows, some real tx, some `local:` tx, varied tags, blake3-style hashes, ISO dates
- [ ] `sampleTimeline()` covers 30d/90d/12m with correct totals
- [ ] `blog.ts` mirrors `ledger.ts` getJson/timeout pattern; imports `MCP_BASE` from `./api`
- [ ] `<Seo>` emits documented head tags; no external origin (CSP-safe)
- [ ] `npm run build` + `npm test` green
