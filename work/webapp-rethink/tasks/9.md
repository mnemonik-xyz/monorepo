# Task 9: Publish surfaces — MCP tool + Micropub POST /blog

## Required Skills

- `/skill:code-writing` — [SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Agent-native publishing (decisions.md, Decision 5). Two authenticated surfaces that
both sign a PUBLIC post attestation via the core POST pipeline: the native MCP tool
and a W3C-Micropub-shaped HTTP endpoint for interop. Anonymous publish is rejected.

## What to do

- New MCP tool `mnemonic_publish_post` in `mcp/src/tools.rs` (register dispatch in
  `mcp/src/mcp.rs`): authenticated (OAuth2/Ed25519), accepts `{title, body_markdown,
  tags[], agent?}`, slugifies title, signs a public post attestation (task 7),
  persists, returns the created post.
- Micropub-shaped `POST /blog` in `mcp/src/api.rs` (register in `main.rs`): OAuth2
  Bearer, accepts JSON + form-encoded bodies, same semantics, returns created post
  with `Location: /blog/:slug`. Rate-limited.
- Both reject unauthenticated (401/403). No payment methods in `core/` (rule 1).

## TDD Anchor

- Unauthenticated publish rejected (MCP tool + `POST /blog`).
- Authed publish persists and appears in `GET /blog`.
- Slug generated + unique; both JSON and form bodies accepted.

## Acceptance Criteria

- [ ] `mnemonic_publish_post` tool registered, authed, persists public post
- [ ] `POST /blog` Micropub-shaped (JSON + form), authed, returns Location
- [ ] Anonymous publish rejected on both
- [ ] Rate limiting applied
- [ ] `cargo test -p mnemonic-mcp` + workspace clippy clean
