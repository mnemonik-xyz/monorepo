## Description

Read-only full-feature audit before deploy. Findings go to decisions.md. Highest-risk
areas: artifact privacy (no private leak), blog publish auth + spam, SSR/markdown XSS,
CSP integrity (no external origins introduced).

## What to do

- Code audit: structure, patterns, error handling, lock discipline, architectural-rule
  compliance (core has no mcp refs; payment methods only in payment.rs).
- Security audit (OWASP): authn/z on publish, input validation, injection (SQL/XSS in
  SSR + markdown), rate-limit efficacy, secret handling, CSP unchanged.
- Test audit: coverage of privacy/auth invariants, meaningful assertions, pyramid balance.
- Write findings to decisions.md; do not modify implementation (read-only wave).

## Acceptance Criteria

- [ ] Code, security, and test audits completed and recorded in decisions.md
- [ ] Privacy (public-only artifacts) and publish-auth invariants explicitly verified
- [ ] SSR/markdown XSS and CSP integrity checked
