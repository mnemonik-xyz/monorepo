# Task 10: Discovery + syndication (AgentCard skill, Micropub link, RSS/Atom)

## Required Skills

- `/skill:code-writing` — [SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Make the publish capability discoverable and the blog syndicable. A2A is discovery
only ("movement, not memory") — advertise the skill on the AgentCard; do not build an
A2A publishing transport. Add Micropub endpoint discovery and a feed.

## What to do

- Add a publish skill entry to `webapp/public/.well-known/agent.json` (and/or the
  `x-mnemonic` AgentCard extension per work/a2a-bridge) describing
  `mnemonic_publish_post` + the Micropub endpoint.
- Add Micropub discovery to `webapp/index.html` head:
  `<link rel="micropub" href="https://mcp.mnemonik.xyz/blog">` (+ authorization/token
  endpoints if applicable). Keep CSP intact (no new external origins).
- Add an RSS/Atom feed route in `mcp/` (e.g. `GET /blog/feed.xml`) emitting published
  posts; link from index.html (`<link rel="alternate" type="application/atom+xml">`).

## TDD Anchor

- feed route returns well-formed Atom/RSS XML for sample posts.
- `agent.json` parses and contains the publish skill.
- index.html contains `rel="micropub"` + `rel="alternate"` feed link.

## Acceptance Criteria

- [ ] AgentCard advertises the publish skill (valid against its schema)
- [ ] index.html has Micropub + feed discovery links; CSP unchanged
- [ ] `/blog/feed.xml` returns valid feed XML
- [ ] `cargo test -p mnemonic-mcp` + build green
