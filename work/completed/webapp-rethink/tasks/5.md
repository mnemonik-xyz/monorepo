- Re-skin `webapp/src/pages/Landing.tsx` with the new design tokens. PRESERVE every
  existing `data-testid` (protocol-thesis, traction-strip, quickstart, how-it-works,
  cta-get-started, …) and the "Mnemonic Protocol" heading so existing tests/e2e stay
  green. Render `<Seo>`. Add entry points to /ledger, /analytics, /blog.
