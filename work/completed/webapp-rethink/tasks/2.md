# Task 2: Ledger page (recalled artifacts on node)

## Required Skills

- `/skill:code-writing` — [SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

The `/ledger` page: a forensic feed of recalled artifacts saved on the node, in
the Evidence Ledger aesthetic. It is the public "proof of work" of the protocol —
real signed memories, their hashes, and their on-chain anchors.

## What to do

- Create `webapp/src/pages/Ledger.tsx` (route owned by task 5). Use `SiteHeader` +
  `SiteFooter`; render `<Seo>`.
- Fetch via `fetchArtifacts({q})`. Render receipt/evidence cards: content excerpt,
  blake3 `content_hash` in mono with copy-to-clipboard, tags, write_mode badge
  (on-node mint / on-chain purple), Solana + Arweave explorer links via
  `solanaTxUrl`/`arweaveTxUrl` (render `local:` tx as plain text), `created_at`,
  and a "SEALED" stamp for on-chain rows.
- "Recall by meaning" search input (filters text/tags) + write_mode filter chips.
- Loading / empty / error states; show a "sample · not live" banner when `sample:true`.

## TDD Anchor

- `src/pages/Ledger.test.tsx` — renders cards from sample; `local:` tx not a link;
  search filters list; sample banner shown when `sample:true`.

## Acceptance Criteria

- [ ] Cards show content, hash (copy works), tags, mode badge, explorer links
- [ ] `local:` tx rendered as plain text, not a link
- [ ] Search/filter narrows the list
- [ ] Loading/empty/error states present; sample banner when applicable
- [ ] Accessible: semantic list, aria labels, keyboard-focusable copy; reduced-motion respected
