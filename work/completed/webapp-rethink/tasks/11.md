# Task 11: Backend integration tests (artifacts privacy, publish auth)

## Required Skills

- `/skill:code-writing` — [SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

End-to-end backend tests across `mcp/` + `core/` for the new data and publishing
paths. The privacy guarantee (public-only artifacts) and the auth guarantee
(no anonymous publish) are the two highest-value assertions.

## What to do

- Add integration tests covering:
  - `GET /artifacts` returns ONLY `visibility=public` (seed private + public; assert private never leaks).
  - `GET /analytics/attestations` aggregation across write_mode split and ranges.
  - `POST /blog` + `mnemonic_publish_post`: reject unauthenticated; accept authed;
    post appears in `GET /blog` and `/blog/:slug`; slug uniqueness.
  - `blog_posts` migration idempotent (run twice).
  - `feed.xml` well-formed.
- Use `mcp/src/test_support.rs` + `MockEmbedder`. Deterministic (injectable, not timing-based).

## TDD Anchor

This IS the test task — the listed assertions are the deliverable and must pass.

- [ ] Publish auth reject/accept tests passing
