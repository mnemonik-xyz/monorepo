# Task 15: Cross-platform manual smoke matrix

## Description

Wave 3's CI tests cover Linux + Secret Service only. macOS Keychain and Windows Credential Manager need human-driven verification on real hardware because no free CI runner can drive them. Wave 5 Task 15 runs the matrix from tech-spec §Testing Strategy.

This is a sign-off task. Findings (pass / fail / observations per row) are appended to `decisions.md`. Fail-rows block release.

## What to do

For each platform row in the matrix, run the script and record results:

| Platform | Keychain | Bootstrap | Migration | Status drift | Push-to-webapp |
|----------|----------|-----------|-----------|--------------|----------------|
| macOS 14 | Keychain | ✓ | ✓ | ✓ | ✓ |
| macOS 13 (regression check) | Keychain | ✓ | ✓ | ✓ | ✓ |
| Ubuntu 22 + gnome-keyring | Secret Service | ✓ | ✓ | ✓ | ✓ |
| Ubuntu 22 + kwallet | Secret Service | ✓ | ✓ | ✓ | ✓ |
| Ubuntu 22 headless (no D-Bus) | n/a | file-fallback | n/a | ✓ | ✓ |
| Windows 11 | Credential Manager | ✓ | ✓ | ✓ | ✓ |
| Windows 10 (regression check) | Credential Manager | ✓ | ✓ | ✓ | ✓ |
| Docker alpine | n/a | file-fallback | n/a | ✓ | ✓ |

### Per-row script

1. **Bootstrap from clean state:**
   ```
   rm -rf ~/.mnemonic
   # On macOS/Linux additionally clear keychain:
   security delete-generic-password -s xyz.mnemonik.identity -a default 2>/dev/null
   # Or
   secret-tool clear service xyz.mnemonik.identity account default 2>/dev/null
   # Or Windows
   cmdkey /delete:xyz.mnemonik.identity 2>nul

   mnemonic whoami
   ```
   Expected: single stderr line `mnemonic: identity created did:sol:... stored in <storage>`, then pubkey on stdout. `~/.mnemonic/identity.json` exists in stub shape (or legacy for headless/Docker).

2. **Migration:** seed a legacy `identity.json` (use `tests/fixtures/legacy-identity.json`), then run `mnemonic whoami`. Confirm same pubkey returned, file shape now stub (or legacy if keychain unavailable). Keychain entry present.

3. **Status drift detection:**
   - Generate a known JWT with sub != local pubkey (use a CLI fixture or a test endpoint).
   - Write to `~/.mnemonic/token.json`.
   - Run `mnemonic identity status`. Expected: exit 3, output contains "DIVERGED".

4. **Push-to-webapp:**
   - Run `mnemonic identity push-to-webapp --code-only` against staging.
   - Receive short_code.
   - On a logged-in browser, open `https://staging.mnemonik.xyz/install?pull=<short_code>`.
   - Confirm webapp shows redemption modal and applies the keypair.
