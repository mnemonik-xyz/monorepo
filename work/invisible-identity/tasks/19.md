# Task 19: Pre-deploy QA gate

## Description

Final sign-off before merging to `main`. Single gate task that aggregates all previous wave outputs into a one-page release checklist. PR merge is blocked until every checkbox is green.

Per project convention (CLAUDE.md §Spec-driven workflow): "Pre-deploy QA gates the merge."

## What to do

Run the checklist below in order. Each line must be green before proceeding.

### Wave 1 — Rust foundation

- [ ] `cargo build --workspace --release` succeeds.
- [ ] `cargo test --workspace --no-fail-fast` passes (≥ existing 90 + new identity tests).
- [ ] `cargo clippy --workspace --all-targets -- -D warnings` clean.
- [ ] `cargo fmt --all -- --check` clean.
- [ ] `grep -rn "load_or_create_keypair" .` returns 0 matches (Decision 4).
- [ ] `core/Cargo.toml` lists `keyring = "2"` and `crypto_box = "0.9"`.
- [ ] `core/src/identity/` contains `keystore.rs`, `keystore_os.rs`, `keystore_file.rs`, `keystore_memory.rs`, `ensure.rs`.

### Wave 2 — Node foundation

- [ ] `cd packages/cli && npx tsc -b` clean.
- [ ] `cd packages/cli && npx vitest run` all green.
- [ ] `cd packages/sdk && npx vitest run` all green.
- [ ] `packages/cli/package.json` lists `@napi-rs/keyring`, `qrcode-terminal`, `@noble/curves`.
- [ ] `npm pack` from `packages/cli` produces a `.tgz` under the size budget (per `work/mnemonic-cli/` thresholds).
- [ ] `node dist/cli.js --help` runs without creating `~/.mnemonic/`.

### Wave 3 — Cross-language interop

- [ ] CI job `cross-lang-keychain` green on the latest commit.
- [ ] `tests/cross-lang/keychain.sh` passes locally on a Linux+gnome-keyring host.
- [ ] Golden byte-equality tests pass in both Rust and Node.

### Wave 4 — Sync surfaces

- [ ] `mnemonic identity status` returns 0/3 exit codes correctly across synced and diverged scenarios.
- [ ] `mnemonic identity push-to-webapp` issues a ticket and prints QR + short code.
- [ ] `mnemonic identity pull-from-webapp <short_code>` redeems and adopts a remote keypair.
- [ ] Webapp `/install` deeplinks open Cursor / VS Code with baked JWT.
- [ ] IdentityPanel drift-warning modal blocks destructive replacement.
- [ ] Existing webapp ticket flow (Send-to-CLI from `work/mnemonic-cli/`) still works (regression check).

### Wave 5 — Audits + archival

- [ ] Task 15 sign-off: at least one row per OS family passes the manual smoke matrix.
- [ ] Task 16 sign-off: security review complete, no critical/high outstanding.
- [ ] Task 17 sign-off: code review complete, no critical outstanding.
- [ ] Task 18 sign-off: `work/keypair-sync/` archived; cross-references updated.
