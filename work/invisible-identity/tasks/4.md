# Task 4: Wire `ensure()` into `mcp/src/main.rs`

## Description

Closes Wave 1 by making the Rust mcp-server use the new bootstrap. Replaces the existing direct `load_or_create_keypair` call with `mnemonic_core::identity::ensure()`. After this task, `mcp-server stdio` on a fresh machine creates an identity without any user action.

Also adds the stdio integration test that boots the server on an empty `~/.mnemonic/` and runs `mnemonic_whoami` JSON-RPC end-to-end.

## What to do

1. **Edit `mcp/src/main.rs`:**
   - Remove the existing `let keypair = load_or_create_keypair(&identity_path)?;` call.
   - Replace with `let identity = mnemonic_core::identity::ensure()?;`.
   - Update downstream callsites that previously took `keypair` to consume `identity` (likely `McpState::new(identity, ...)`).
   - If the existing `identity_path` argv flag or env var was used, decide: either drop it (`ensure()` uses the standard path internally), or pass it through to `ensure_with_stores()` for tests. Recommend: drop the flag for now, lean on the standard path.

2. **Verify no other callsites of `load_or_create_keypair` remain:**
   ```
   grep -rn "load_or_create_keypair" .
   ```
   Must return zero matches across the workspace.

3. **Add stdio integration test** at `mcp/tests/integration_bootstrap.rs`:
   - Spawn `target/debug/mnemonic-mcp --transport stdio` with `HOME=<tempdir>` env var.
   - Send `{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"mnemonic_whoami","arguments":{}}}` over stdin.
   - Read stdout, parse response, assert `result.pubkey` matches the pubkey written to `<tempdir>/.mnemonic/identity.json`.
   - Assert the server started without prompts (no stderr noise beyond the single creation line).

4. **Smoke verify locally:**
   ```
   rm -rf /tmp/mn-smoke && HOME=/tmp/mn-smoke cargo run -p mnemonic-mcp -- --transport stdio
   # send mnemonic_whoami via stdin
   ```
   Server starts, identity created in `/tmp/mn-smoke/.mnemonic/`, whoami returns the pubkey.

5. **CI:** add the integration test to `cargo test --workspace` invocation. Should already be picked up automatically by `[[test]]` discovery.
