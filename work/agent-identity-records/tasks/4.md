# Task 4: WASM and SDK functions

## What to do

1. Export `agent_record_sign`, `agent_record_verify` and `agent_chain_resolve`
   from `core/src/wasm/mod.rs`.
2. Add `packages/sdk/src/agent.ts`: `buildAgentRecord`, `signAgentRecord`
   (takes a `Signer`), `publishAgentRecord`, `resolveAgent` (server or direct
   Arweave source) and `verifyAgentChain`.
3. `resolveAgent` always verifies the chain locally, whatever the source.
4. Keep the highest verified head for each `id` (rollback guard). Reject a chain
   without that head, unless rule 5 discards the head.

## TDD anchors

- SDK parity test on the task 1 golden vectors.
- `resolveAgent` rejects a server response whose chain does not verify.
- `resolveAgent` rejects a truncated chain after it saw a higher head.

## Done when

- `npm run build:wasm:sdk` and `npm test -w @mnemonik-xyz/sdk` pass.
