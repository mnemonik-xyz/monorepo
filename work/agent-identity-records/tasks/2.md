# Task 2: Publish and resolve on the server

## What to do

1. Add the `agent-record` adapter to `mcp/src/ingestion.rs`: `verify_record`,
   then the authorization check (rule 1, 3 or 4 for a known parent). Do not
   require the JWT subject to equal the record signer. Charge payment and quota
   to the JWT subject. Deliver exact bytes with tags `Mnemonic-Type=agent-record`,
   `Agent-Id`, `Agent-Seq` and `Producer` (the record signer).
2. Add an index table in `core/src/storage/sqlite.rs` keyed by
   `(id, seq, payload hash)`, with parameterized queries only.
3. Add index rebuild from Arweave by the `Agent-Id` tag through the Irys GraphQL
   endpoint. Report a budget limit as `incomplete`.
4. Add `GET /api/agents/{id}` in `mcp/src/api.rs` and mount it outside the
   bearer-auth layer in `mcp/src/main.rs`.
5. Add the read-only MCP tool `mnemonic_resolve_agent` in `mcp/src/mcp.rs` and
   `mcp/src/tools.rs`, and add it to `ALLOWLIST_TOOLS_CALL_NAMES` in
   `mcp/src/oauth/mod.rs`.
6. In the same task, update the tool docs and counts from 11 to 12:
   `docs/tools.md`, `AGENTS.md`, `CLAUDE.md`, and the tool-count checks in
   `mcp/src/mcp.rs` and `mcp/tests/oauth_tool_call.rs`.
7. Never hold the store mutex across `.await`.

## TDD anchors

- `public_read_routes`: `GET /api/agents/{id}` for active, rotated, revoked,
  conflicted and incomplete fixtures, with no token.
- `tools/call mnemonic_resolve_agent` works with no token.
- Ingestion accepts a rotation signed by a key with no account.
- Ingestion rejects a bad signature, a wrong content type, an unauthorized record
  for a known parent and an oversize record.
- Rebuild from Arweave fixtures equals the live index.
