# Task 2: Publish and resolve on the server

## What to do

1. Add the `agent-record` adapter to `mcp/src/ingestion.rs`: validate with
   `verify_record`, deliver exact bytes with tags `Mnemonic-Type=agent-record`,
   `Agent-Id`, `Agent-Seq`. Accept a record that conflicts with the index.
2. Add an index table in `core/src/storage/sqlite.rs` keyed by
   `(id, seq, hash)`, with parameterized queries only.
3. Add index rebuild from Arweave by the `Agent-Id` tag through the configured
   enumeration source.
4. Add `GET /api/agents/{id}` in `mcp/src/api.rs` and the read-only MCP tool
   `mnemonic_resolve_agent` in `mcp/src/mcp.rs` and `mcp/src/tools.rs`. Both are
   free and need no authentication.
5. Never hold the store mutex across `.await`.

## TDD anchors

- `public_read_routes`: `GET /api/agents/{id}` for active, rotated, revoked and
  conflicted fixtures.
- Ingestion rejects a bad signature, a wrong `protocol` and an oversize record.
- Rebuild from Arweave fixtures equals the live index.
