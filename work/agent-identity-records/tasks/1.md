# Task 1: Record schema, signing and chain resolver

## What to do

1. Make `serde_jcs` a non-optional dependency of `mnemonic-core`. Today only the
   `a2a-experimental` feature enables it.
2. Add `core/src/identity/record.rs` (portable, builds for `wasm32`):
   `AgentRecord` with `serde(deny_unknown_fields)`; `record_id` (blake3 of the
   seq 0 JCS without `id`); `sign_record` (JCS, COSE_Sign1, protected content
   type `application/mnemonic-agent-record+json`); `verify_record` (signature,
   content type, only `kid` in the unprotected header, canonical JCS,
   `protocol`, `signer == key`, limits, AgentCard rules, `valid_until` limit).
3. Add `resolve_chain(records) -> Resolution` that applies chain rules 1 to 9 and
   returns `status`, `head` and `keys_history`. Each input record carries its
   anchor time. Rule 8 rejects a record whose `created_at` is more than 10
   minutes after its anchor time, and does not count a record without one.
4. Add golden vectors in `core/tests/agent_record_golden.rs` behind
   `golden-fixtures`: fixed seeds and timestamps.
