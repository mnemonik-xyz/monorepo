# Task 3: CLI `mnemonic agent`

## What to do

1. Add `mnemonic agent init`: build record `seq 0` from the current identity, make
   a next key, write it to a file that the user moves offline, and print the
   warning once.
2. Add `publish` (update: services, agent card, accounts, `valid_until`),
   `rotate --next-key-file` (rotation; makes and writes the following next key),
   `revoke`, and `show <id>` (resolve and verify locally).
3. Every command shows the record and asks for confirmation before it publishes.

## TDD anchors

- `init` then `rotate` then `show` resolves to the rotated key.
- `rotate` with a wrong next key file fails before any network call.

## Done when

- `npm test -w @mnemonik-xyz/cli` passes.
- The CLI README documents the commands.
