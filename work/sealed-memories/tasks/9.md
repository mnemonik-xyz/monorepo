# Task 9: Extension — seal before cloud sync

## Description

The extension keeps memories on the device and syncs to the cloud
(`packages/extension/src/runtime/sync/cloud-client.ts`). Sync must send only
sealed artifacts (tech-spec §8.2).

## What to do

1. Seal each memory with the WASM API before `cloud-client` sends it.
2. Anchored writes: sign the outer CBOR (`runtime/sign/cose.ts`) and post to
   `/api/anchor-sealed`.
3. Restore (`popup/onboarding/Restore.tsx`): download sealed blobs, open with
   the identity key, rebuild the local store.
4. Unlock cache: hold the X25519 secret in memory for 15 minutes (tech-spec §7.5).
5. Check task 3 golden vectors with `bun test`.

## Acceptance

- `bun test` passes. A sync request body never contains plaintext (test).
