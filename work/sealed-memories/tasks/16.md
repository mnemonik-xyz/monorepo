# Task 16: Audit — cryptography and secret handling

Read-only. Write findings to `work/sealed-memories/decisions.md` under
"Audit findings".

## Check

1. Primitives match tech-spec §5: XChaCha20-Poly1305, HPKE suite
   `0x0020/0x0001/0x0003`, `info`/`aad`/AD contents, `kc` check before use.
2. The `hpke` crate: version, maintenance, known advisories (`cargo audit`).
   If rejected, record the fallback decision (tech-spec §5.2).
3. Nonces come from the OS random source; no nonce reuse under one `K`
   (streams use the counter layout).
4. All-zero shared secret and small-order keys rejected.
5. Secrets (`K`, `RK`, X25519 secret, plaintext) are zeroized and never
   logged, put in errors, metrics, or panics. Grep and log-capture tests.
6. Hosted path: pending entries and saved rows hold no plaintext or embedding
   for sealed writes. `PendingBundles` expiry still 300 s.
7. The server never receives `K` on share, link or E2E paths.
8. Webapp `/m/` route: no third-party scripts; fragment never sent.
9. Docs state the revocation limit, hosted transient exposure, recall-session
   exposure and metadata leaks.
