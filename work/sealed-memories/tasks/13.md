# Task 13: Hosted recall session (opt-in)

## Description

Optional hosted recall of sealed memories for pure hosted connectors
(tech-spec §7.4). Build only if the owner accepts D-3 option d.

## What to do

1. Per-owner `RK`, wrapped to the owner X25519 key, in `owner_recall_keys`.
2. Hosted sealed writes (task 6) also store `K` wrapped under `RK` and the
   f32 embedding encrypted under `RK` in `sealed_index`, when the owner
   turned the feature on.
3. `POST /api/recall-session {rk, ttl}`: store `RK` in RAM only (not in
   SQLite, logs or metrics). `DELETE` ends it. Default limit 60 minutes.
4. `mnemonic_recall` during a session: decrypt embeddings in memory, rank,
   open top results, return plaintext with `sealed: true`.
5. Webapp toggle and "session on" banner with the honest label.
6. Audit log of session start and end per owner (no content).

## Acceptance

- After the session ends, recall returns `sealed_hidden` again.
- A restart drops all sessions.
