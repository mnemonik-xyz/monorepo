# Task 12: Local MCP client-side sealed recall and unlock cache

## Description

The stdio local MCP is the easiest E2E client for Claude Desktop and Cursor
(tech-spec §7.3, §7.5). It seals, anchors through the hosted service, and
recalls sealed memories on the device.

## What to do

1. Unlock cache in `core/src/identity/`: `UnlockedX25519` held in
   `Zeroizing`, read once on the first open, `MNEMONIC_UNLOCK_TTL`
   (default: process lifetime). Config in `mcp/src/config.rs`.
2. stdio `mnemonic_sign_memory` with `participate` + `private`: seal locally,
   sign with the agent key, anchor (own Arweave config or hosted
   `/api/anchor-sealed`).
3. On-device `local` rows follow D-6 (recommended: plaintext on device).
4. stdio `mnemonic_recall`: include sealed rows from the device index; open
   grants received from `GET /api/grants` into the local index with
   provenance `source: foreign` and spotlighting.
5. Never hold the store mutex across `.await` while decrypting.
6. Docs: `docs/tools.md` stdio section, `packages/mcp/README.md`, WHITEPAPER §7 keychain rule.

## Acceptance

- One keychain read per process in a test with 10 sealed recalls.
- Workspace tests pass with `test-support`. Clippy clean.
