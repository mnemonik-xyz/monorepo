# Task 11: CLI sealed commands and local index

## Description

Make the CLI an E2E client (tech-spec §8.2, §7.3, §7.5).

## What to do

1. `mnemonic sign` (`packages/cli/src/commands/sign.ts`): default is a sealed
   `local` write through `sealMemory`. It needs only the public key, so no
   keychain prompt. `--anchor` seals and signs (one keychain read).
   `--public` writes plaintext (anchor only).
2. `mnemonic open <hash|link>`, `mnemonic share <hash> --to <did|key>|--link`,
   `mnemonic grants`.
3. `mnemonic recall`: own server results plus the local sealed index in
   `~/.mnemonic/sealed-index/` (rebuild from `GET /api/sealed`).
4. Keychain: read the secret only for `open`, `share`, `--anchor`, and the
   first sealed recall in a run.
5. Update the header comment of `sign.ts`, `packages/cli/README.md`,
   `docs/QUICKSTART.md`.

## Acceptance

- `npm test -w @mnemonik-xyz/cli` passes. A default `sign` test proves the
  key store is not read.
