# Task 7: SDK sealed support

## Description

Add sealed operations to `@mnemonik-xyz/sdk` (tech-spec §8.1 step 5, §8.2,
§7.3). All crypto goes through the WASM bindings from task 5.

## What to do

1. `signMemory` (`packages/sdk/src/client.ts:230`): when the pending bundle is
   SEALED_V1, unwrap `K`, check `kc`, decrypt, and compare the text with the
   input. On mismatch throw `IntegrityError` and do not sign.
2. `sealMemory(content, {mode, tags, embedder?})`: E2E path. Posts to
   `/api/anchor-sealed` or `/api/store-sealed` (task 10).
3. `openMemory(hashOrBytes)`, `share(memoryHash, reader | "link")`,
   `importLink(url)`, `listGrants()`.
4. `recallSealed(query, {embedder?})`: rebuild a local index from
   `GET /api/sealed`, rank locally. Pluggable `Embedder` interface; default
   uses `POST /api/embed` (D-4).
5. Check task 3 golden vectors in vitest.
6. Update `packages/sdk/README.md` (available now / planned per method).
