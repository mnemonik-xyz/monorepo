# Task 1: Core sealed crypto primitives

## Description

Add a portable module `core/src/sealed/` (builds for native and wasm32) with
the primitives from tech-spec §5. Replace the unused `core/src/encrypt.rs`
(F3). Nothing in `mcp/` changes.

## What to do

1. Dependencies in `core/Cargo.toml`: `chacha20poly1305` (XChaCha20Poly1305),
   `hpke` (X25519HkdfSha256, HkdfSha256, ChaCha20Poly1305), `zeroize`,
   `getrandom` with the `js` feature for wasm32. Check that each builds for wasm32.
2. `sealed/keys.rs`: `x25519_public_from_ed25519(&[u8;32])` (via
   `VerifyingKey::to_montgomery`) and `x25519_secret_from_ed25519(&SigningKey)`
   (via `to_scalar_bytes`). Reject small-order input points.
3. `sealed/content.rs`: `encrypt_content(K, nonce, ad, padded_pt)` and
   `decrypt_content`. Padding to 256-byte buckets with a length prefix (§5.6).
   `key_commitment(K)` with `blake3::derive_key("mnemonic sealed v1 key commitment", K)`.
4. `sealed/wrap.rs`: `wrap_key(K, pkR, ct_hash, author_did)` and `unwrap_key`
   with HPKE base mode single-shot, `info` and `aad` as in §5.2. Reject the
   all-zero shared secret.
5. Wrap `K` and secrets in `Zeroizing`. No `unwrap()` outside tests.
6. Delete `core/src/encrypt.rs` and its `pub mod` line in `core/src/lib.rs`
   after a caller search confirms no users. Add `pub mod sealed` (portable).
7. Update `work/noncustodial-paradigm/IMPLEMENTATION_STATUS.md` W6 lines.

## TDD anchors

- Round-trip content and wrap. Wrong key, tampered nonce, ct, ad, enc, wk fail.
- RFC 9180 Appendix A.2 base-mode vector passes.
- Ed25519 to X25519 output equals libsodium output for three fixed keys
  (store the expected hex in the test).
- All-zero shared secret and small-order keys are rejected.

## Acceptance

- `cargo test -p mnemonic-core sealed` passes; `cargo build --target wasm32-unknown-unknown -p mnemonic-core --features wasm` passes.
- clippy `-D warnings` clean.
