# Task 7: Docker Compose + nginx config + Ollama model

## Required Skills

Before starting, load: `/skill:deploy-pipeline`

## Description

Create Docker Compose configuration for single-server deployment. Three services: nginx (serves static React build + reverse proxies /mcp, /chat, /download-knowledge, /health to MCP -- blocks /admin/stats), mcp (existing Dockerfile), ollama (custom Dockerfile that pre-pulls qwen2.5:3b at build time). Nginx handles SSL termination placeholder (certbot added during deploy). Ollama entrypoint issues warm-up inference request before accepting traffic. Keypair mounted as read-only volume with chmod 400 permissions. Keypair not committed to repo.

## Verify-smoke
