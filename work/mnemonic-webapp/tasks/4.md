# Task 4: Initialize webapp project (React + Vite + Tailwind)

## Required Skills

Before starting, load: `/skill:infrastructure-setup`

## Description

Scaffold the `webapp/` directory with Vite + React + TypeScript + Tailwind CSS. Configure the dark theme colors from UX guidelines (#0A0F1E background, #00D4B4 teal accent, #9945FF purple accent, #FFFFFF text, #8B9BC0 muted text). Add Playwright as a dev dependency with basic config. This creates the foundation that Tasks 5 and 6 build on.
