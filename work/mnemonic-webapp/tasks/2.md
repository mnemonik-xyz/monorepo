# Task 2: RAG seeding -- whitepaper chunking + sign_memory + artifact generation

## Required Skills

Before starting, load: `/skill:code-writing`

## Description

Implement the startup seeding routine in `mcp/src/seed.rs`. On first server start, parse `docs/WHITEPAPER.md` by `##` section headers (splitting large sections at `###` level if >~500 tokens), call `sign_memory()` for each chunk with tags `["protocol-knowledge", "whitepaper"]`, then generate a downloadable `.zip` artifact containing a Markdown file (with YAML frontmatter: content_hash, signer_pubkey, timestamp) and a JSON sidecar with structured metadata. Skip seeding if `store.count() > 0`. The `.zip` path is resolved to an absolute canonical path and stored in `McpState` for the download handler.

Add `zip` crate to `mcp/Cargo.toml`. Call seeder from `main.rs` after `McpState` initialization.

## Verify-smoke

`cargo run -p mnemonic-mcp` starts, seeds whitepaper chunks, creates `.zip` artifact on disk.

- **Create:** `mcp/src/seed.rs`
