# Task 1: Extend MCP config with Ollama env vars

## Required Skills

Before starting, load: `/skill:code-writing`

## Description

Add Ollama and RAG configuration to the MCP server. Three new env vars (`OLLAMA_URL`, `OLLAMA_MODEL`, `RAG_CHUNK_DIR`) need to be read in `config.rs` and corresponding fields added to `McpState` in `mcp.rs`. This is a prerequisite for all subsequent tasks that use Ollama or generate artifacts.

`OLLAMA_URL` must be validated at startup against a whitelist (`http://localhost:*` or `http://ollama:*`) per Decision 8 (SSRF prevention). Invalid URLs cause a fatal startup error.

## Files

- **Modify:** `mcp/src/config.rs`, `mcp/src/mcp.rs`, `.env.example`
- **Read:** `mcp/src/main.rs`
