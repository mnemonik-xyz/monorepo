# Task 3: POST /chat + rate limiting + GET /download-knowledge endpoints

## Required Skills

Before starting, load: `/skill:code-writing`

## Description

Implement three new HTTP endpoints on the MCP server:

**POST /chat:** Validate input (max 2000 chars, reject empty/missing message with 400). Call `recall()` for top-3 knowledge chunks. Build prompt: system instruction (protocol expert, answer only from context, delimited user query with `[USER_QUERY]...[/USER_QUERY]` tags per Decision 10) + recalled context + user message. POST to Ollama `/api/generate` (stream: false, reqwest client with `redirect(Policy::none())` per Decision 8). Return structured JSON: `{"response": "..."}` on success, `{"error": "...", "code": "..."}` on failure (Decision 9).

**Rate limiting:** Add `governor` + `tower-governor` to `mcp/Cargo.toml`. Apply 10 req/min per IP to `/chat` only. Return 429 with `{"error": "Rate limit exceeded", "code": "rate_limited"}`.

**GET /download-knowledge:** Serve pre-built `.zip` from path stored in McpState. Return 404 if file doesn't exist.

Add all three routes to axum Router in `main.rs`.

## Verify-smoke

`curl -X POST http://localhost:3000/chat -H 'Content-Type: application/json' -d '{"message":"What is Mnemonic?","session_id":"t"}'` returns relevant answer.
