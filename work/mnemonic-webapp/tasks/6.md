# Task 6: Chat interface

## Required Skills

Before starting, load: `/skill:code-writing`

## Description

Build the chat page React component. Message list with user/bot message bubbles, text input field, send button. Client-side session counter (useState, max 50 messages) -- shows "Session limit reached. Start a new session to continue." when hit. Auto-retry on server error (2-3 attempts, exponential backoff). Structured error display per UX guidelines (no casual language, precise problem statements). Calls `POST /chat` on backend with `{"message": "...", "session_id": "..."}`. Handles 400/429/503 error codes with appropriate UI messages.

## Verify-user

Open chat, send a question about the protocol, verify answer appears in bot message bubble.
