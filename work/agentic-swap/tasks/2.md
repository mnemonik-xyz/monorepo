# Task 2: Signed inner payload — build, sign, verify

## Description

Implement `SIGNED_INNER_V1` in `core/src/codec/a2a/inner.rs`: build the JCS
payload, sign it with `sign_cose`, and verify it. Do not change `sign_cose` or
any existing schema.

## What to do

1. Define `SignedInner` with `serde(deny_unknown_fields)`. `body` is a
   `serde_json::Value` object that this module never interprets.
2. `sign_inner(inner, keypair) -> Vec<u8>`: JCS (`serde_jcs`) then `sign_cose`.
3. `verify_inner(cose_bytes, expected_protocol) -> VerifiedInner`: verify the COSE
   signature (`verify_artifact`), parse the payload, require
   `protocol == expected_protocol`, and require that `sender` equals the COSE
   `kid` as raw 32-byte keys. Return the payload, its JCS blake3 hash and the
   exact COSE bytes.
4. Add `ed25519_key_bytes(base58) -> Result<[u8; 32]>` that rejects any value
   that does not decode to exactly 32 bytes. Use it for every key comparison.
