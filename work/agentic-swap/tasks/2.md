# Task 2: Inner message — build, sign, verify

## Description

Implement `AGSWAP_INNER_V1` in `core/src/codec/agswap/inner.rs`: build the JCS
payload, sign it with `sign_cose`, and verify it. Do not change `sign_cose` or
any existing schema.

## What to do

1. Define `AgswapInner` with `serde(deny_unknown_fields)` and the fields of
   task 1.
2. `sign_inner(inner, keypair) -> Vec<u8>`: JCS (`serde_jcs`) then `sign_cose`.
3. `verify_inner(cose_bytes) -> VerifiedInner`: verify the COSE signature,
   parse the payload, require `protocol == "mnemonic.agswap.inner.v1"`, and
   require that `sender` equals the COSE `kid` as raw 32-byte keys.
4. Add `ed25519_key_bytes(base58) -> Result<[u8; 32]>` that rejects any value
   that does not decode to exactly 32 bytes. Use it for every comparison.
