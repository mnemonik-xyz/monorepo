# Task 4: Seal and open over sealed A2A

## Description

Compose the inner message with the existing sealed A2A path in
`core/src/codec/a2a/signed.rs`. No change to `SEALED_V1`, grants or the A2A
binding format.

## What to do

1. `seal_negotiation_message(inner_cose, keypair, recipient, context_id, prev_id)`:
   put the inner COSE bytes in one A2A DataPart with media type
   `application/vnd.mnemonic.agswap.inner+cose`, then call `prepare_signed_a2a`
   with a grant for the recipient.
2. `open_negotiation_message(bytes, local_keypair, transcript, nonce_store)`:
   run checks 1 to 10 of the tech spec in order:
   `verify_signed_a2a` → `open_signed_a2a` → exactly one inner DataPart →
   `verify_inner` → sender equals binding signer → recipient equals the local
   key and one grant `reader` → `session_id` equals `context_id` →
   `Transcript::apply` → nonce is new → time window.
3. Define a `NonceStore` trait (`seen`, `record`). Record the nonce only after
   every other check passes.
4. All key comparisons use the 32-byte helper of task 2.
