# Task 4: Profile checks helper and nonce store

## Description

Add one optional SDK helper that runs the sealed A2A V2 profile checks after
`openA2AAttestation`. It uses only existing core and WASM functions. No change to
`A2aInnerBinding` or any signed format.

## What to do

1. Add `checkSealedProfile(opened, expected)` to `packages/sdk/src/a2a.ts`. It runs
   open checks 1 to 6 of the tech spec in order: `innerSigned` present, exact
   recipient set, `prev_id` equals the session head, payload `protocol`, expiry
   and skew, new nonce.
2. Add a `NonceStore` interface and a local implementation next to the existing
   local A2A state. Record a nonce only after every other check passes.

## TDD anchors

- One failing test per check, with the existing V2 fixtures
  (`packages/sdk/test/fixtures/sealed-a2a.json`) plus profile payloads.
- A legacy V1 sealed envelope is rejected (no `innerSigned`).

- `npm test -w @mnemonik-xyz/sdk` passes.
