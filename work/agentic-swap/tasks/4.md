# Task 4: Seal and open over sealed A2A

## Description

Compose the signed inner payload with the existing sealed A2A path in
`core/src/codec/a2a/signed.rs`. No change to `SEALED_V1`, grants or the A2A
binding format. The functions take the protocol tag from the caller and never
interpret `body`.

## What to do

1. `seal_signed_inner(inner_cose, keypair, recipients, context_id, prev_id)`:
   put the inner COSE bytes in one A2A DataPart with media type
   `application/vnd.mnemonic.signed-inner+cose`, then call `prepare_signed_a2a`
   with a grant for each recipient.
2. `open_signed_inner(bytes, local_keypair, expected_protocol, session_head,
   nonce_store)`: run checks 1 to 10 of the tech spec in order. Return the
   `VerifiedInner` of task 2.
3. Define a `NonceStore` trait (`seen`, `record`). Record the nonce only after
   every other check passes.
4. All key comparisons use the 32-byte helper of task 2.
