# Task 1: Freeze `SIGNED_INNER_V1` and add the module skeleton

## Description

Fix the exact shape of the generic signed inner payload before any
implementation. Add an empty module so that wave 2 tasks do not edit the same
shared files. Nothing in this task names a swap or any other application.

## What to do

1. In `tech-spec.md`, write the final field list, types and limits of
   `SIGNED_INNER_V1`: `protocol` (ASCII, 1 to 128 bytes), `session_id`,
   `prev_hash`, `nonce`, `created_at`, `expires_at`, `sender`, `recipient`, `body`
   (JSON object, size limit). Identities are bare base58 Ed25519 keys.
2. State the media type `application/vnd.mnemonic.signed-inner+cose`.
3. Add `core/src/codec/a2a/inner.rs` with empty items, behind the existing
   `a2a-experimental` feature, and register it in `core/src/codec/a2a/mod.rs`.

## TDD anchors

- `codec::a2a::inner::tests::module_compiles`

## Done when

- `cargo build -p mnemonic-core --features a2a-experimental` succeeds.
- `cargo build --workspace` without the feature still succeeds.
- `decisions.md` records the frozen schema version.
