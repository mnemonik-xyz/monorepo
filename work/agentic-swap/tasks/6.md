# Task 6: Golden vectors, end-to-end test and docs

## Description

Fix the byte format with golden vectors, prove Rust and TypeScript parity, and
run a full exchange end to end with a dummy protocol. Update the docs that
describe sealed A2A.

## What to do

1. Extend `core/tests/a2a_golden_fixtures.rs` (gated by `golden-fixtures` and
   `a2a-experimental`) with `SIGNED_INNER_V1` vectors: fixed seeds, fixed
   timestamps, deterministic output.
2. Emit one vector per accepted case and one per rejected check.
3. Add an SDK test that loads the vectors and checks byte parity.
4. End-to-end test: two local stdio agents exchange three messages of protocol
   `test.echo.v1` and anchor each one with `mnemonic_attest_a2a`.
5. Update `docs/sealed-a2a.md` with the sign, seal, sign construction, the
   identity encoding and the integration boundary rule.

## TDD anchors

- The emitter output is byte-identical on two runs.
- The SDK parity test passes on the emitted vectors.

## Done when

- `cargo test --features "golden-fixtures a2a-experimental" -p mnemonic-core --test a2a_golden_fixtures emit_fixtures -- --ignored --nocapture`
  is deterministic.
- `cargo fmt --all -- --check` and
  `cargo clippy --workspace --all-targets --features mnemonic-mcp/test-support -- -D warnings`
  pass.
- `docs/sealed-a2a.md` is updated in the same PR as the code.
