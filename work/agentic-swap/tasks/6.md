# Task 6: Golden vectors, end-to-end test and docs

## Description

Fix the byte format with golden vectors, prove Rust and TypeScript parity, and
run a full negotiation end to end. Update the docs that describe sealed A2A.

## What to do

1. Add `core/tests/agswap_golden.rs`, gated by `golden-fixtures` and
   `agswap-experimental`, on the pattern of `core/tests/a2a_golden_fixtures.rs`:
   fixed seeds, fixed timestamps, deterministic output.
2. Emit vectors for each message kind and for one rejected case per check.
3. Add an SDK test that loads the vectors and checks byte parity.
4. End-to-end test: two local stdio agents run `rfq → quote → counter →
   accept` and anchor each message with `mnemonic_attest_a2a`. No funds move.
5. Update `docs/sealed-a2a.md` with the inner-signature construction and the
   identity encoding.

## TDD anchors

- `agswap_golden::emit_fixtures` is byte-identical on two runs.
- SDK parity test passes on the emitted vectors.
