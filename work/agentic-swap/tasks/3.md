# Task 3: Key-custody `Signer` trait

## Description

Add a signing interface so that an Ed25519 key can stay in an HSM, a KMS or a
TEE. This is not multi-suite signing (`work/multi-suite-signing/`): the
algorithm, the protected header and the `kid` do not change.

## What to do

1. Add `core/src/identity/signer.rs` with `trait Signer { fn public_key(&self)
   -> [u8; 32]; fn sign(&self, message: &[u8]) -> Result<[u8; 64]>; }` and
   `LocalSigner` over the existing `Keypair`.
2. Add `sign_cose_with(payload, &dyn Signer)` and `sign_artifact_with(…,
   &dyn Signer)` in `core/src/codec/sign.rs`. Make `sign_cose` and
   `sign_artifact` call them with a `LocalSigner`.
3. Keep `alg = EdDSA` and the base58 `kid` exactly as today.
4. Do not add any HSM, KMS or TEE adapter to core.
