# Task 3: Intent id, terms hash and transcript state machine

## Description

Implement `core/src/codec/agswap/intent.rs` and `transcript.rs`. This code is
pure and has no I/O, so it also builds for `wasm32`.

## What to do

1. `intent_id(terms) = blake3(JCS(terms))` and `terms_hash` with the same rule.
2. CAIP-2, CAIP-10 and CAIP-19 parsers that accept only the forms of task 1.
3. `Transcript` holds the ordered inner hashes for one session.
   `Transcript::apply(&VerifiedInner)` enforces:
   - `rfq` first, then `quote`, then any number of `counter`, then one of
     `accept`, `reject`, `expire`;
   - parties alternate after `rfq`;
   - `prev_hash` equals the current head;
   - `accept` references the hash of the last `quote` or `counter`;
   - no message after a terminal kind.
4. `Transcript::hash()` returns the blake3 hash of the terminal inner JCS.
