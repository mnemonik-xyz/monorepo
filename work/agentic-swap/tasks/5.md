# Task 5: WASM wrappers, SDK module and nonce store

## Description

Expose the negotiation to TypeScript. `core/src/wasm/mod.rs` is a common
conflict point; no other task in this wave touches it.

## What to do

1. Add `agswap_seal`, `agswap_open` and `agswap_verify_transcript` to
   `core/src/wasm/mod.rs`, gated by `agswap-experimental`. Convert errors to
   `JsValue` only at this boundary.
2. Add `packages/sdk/src/agswap.ts` with typed wrappers and a `NonceStore`
   implementation next to the existing local A2A state.
3. Follow the key handling of the A2A path in `packages/sdk/src/client.ts`.
   Do not add a new path that passes the raw secret; gap G13 tracks the
   `Signer` interface.
4. Export the module from `packages/sdk/src/index.ts`.

## TDD anchors

- SDK test: seal in one client, open in a second client, transcript hash equal.
- SDK test: replayed message rejected by the nonce store.

## Done when

- `npm run build:wasm:sdk` and `npm test -w @mnemonik-xyz/sdk` pass.
- The SDK README documents the new module as experimental.
