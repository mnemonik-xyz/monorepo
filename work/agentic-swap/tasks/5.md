# Task 5: `verify_cose_payload` in WASM and the SDK

## Description

TypeScript can sign generic COSE today (`sign_cose_payload`), but it cannot
verify a standalone COSE signature. `core/src/wasm/mod.rs` is a common conflict
point; no other task in this wave touches it.

## What to do

1. Add `verify_cose_payload(cose_bytes)` to `core/src/wasm/mod.rs`. It calls
   `verify_artifact`, rejects the input unless the signature is valid, and
   returns the payload bytes and the base58 `kid`.
2. Add `verifyCosePayload` to `packages/sdk/src/cose.ts`.

## TDD anchors

- SDK test: `verifyCosePayload` accepts a `coseSignPayload` output and rejects a
  changed payload byte.

## Done when

- `npm run build:wasm:sdk` and `npm test -w @mnemonik-xyz/sdk` pass.
- The SDK README documents the function.
